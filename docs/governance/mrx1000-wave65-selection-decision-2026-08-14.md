The manifest inventories each received source file, page count, document date, parties as written, referenced exhibit, schedule, addendum, amendment, incorporated item, signature copy, execution record, and later replacement. Its purpose is completeness checking and package identity.

It may provide a blank field structure, a fictional package example, a page-count reconciliation, rules for missing and unreadable pages, rules for separately preserving originals and working copies, and a pre-review completeness audit.
