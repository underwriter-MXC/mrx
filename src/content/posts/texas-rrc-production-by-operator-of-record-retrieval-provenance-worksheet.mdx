> **Public retrieval boundary.** This article records one authorized manual attempt through the Texas Railroad Commission's public **Production by Operator of Record (as shown on RRC Form P-4)** query path. It does not interpret production or establish a current operator, property, tract, lease, well, owner, title, payment, acreage, decimal, tax, reserve, forecast, value, offer, legal position, compliance finding, or transaction. It does not provide legal, title, land, tax, accounting, appraisal, engineering, regulatory, investment, or financial advice. MRX may have an economic interest in a later transaction; when that applies, the buyer relationship is disclosed in writing before an agreement is signed.

A **Texas RRC Production by Operator of Record retrieval** worksheet preserves how one authorized manual attempt was made through one source-labeled route. Its job is administrative: retain the official entry path, exact labels shown, controlled criteria reference, access time and timezone, displayed state, historical-scope note, evidence reference, source limitations, and a bounded retrieval status.

Use only **located**, **not located**, or **unverified**. Those terms describe the attempt, not the underlying rights or facts. A worksheet cannot decide which company currently operates a property, whether a production record belongs to a mineral owner, whether a payment is correct, or what an interest is worth.

## Begin at the named public route

The Texas RRC [Research Queries](https://www.rrc.texas.gov/resource-center/research/research-queries/) directory identifies **Production Reports Query (Form PR)** and labels the query as updated nightly. The linked [Production Report Queries](https://webapps.rrc.texas.gov/PR/publicQueriesMainAction.do) application currently separates three paths:

- **Production by Lease**;
- **Production by Filing Operator**; and
- **Production by Operator of Record (as shown on RRC Form P-4)**.

Select the third path only. Record the directory URL, launched application URL, and route wording exactly as displayed. If the route is missing, renamed, redirected, or materially changed, stop and use **unverified**. Do not switch to Production by Lease or Production by Filing Operator merely because another path produces a screen or result.

The directory also warns that automated tools retrieving volumes of data can degrade RRC systems and may cause a session to end. It describes online query data as informational, continually updated, not an authoritative public record, and without legal force. Preserve those source limits with the worksheet rather than turning a public-query screen into a conclusion.

## Assign one attempt ID

Give each manual session a neutral identifier such as `TX-RRC-POR-01`. The ID refers to the retrieval attempt only. It is not an operator number, lease number, well identifier, property ID, owner record, title reference, royalty account, production conclusion, or transaction file number.

The attempt header should record:

- worksheet version and neutral attempt ID;
- official directory and application URLs;
- exact **Production by Operator of Record** route wording;
- access date, time, and timezone;
- preparer role and authorized purpose;
- controlled storage reference for criteria and retained evidence;
- displayed navigation, validation, result, empty-result, error, timeout, maintenance, or access state;
- the post-February-11-2005 route note and PDQ pointer as displayed; and
- the RRC informational, non-authoritative, no-legal-force limitation.

Create a new attempt ID for every rerun. Do not replace an earlier record when a criterion, validation message, result page, source notice, or access condition changes. A dated sequence is more useful than a worksheet that silently rewrites the past.

## Record the visible criteria without publishing identifiers

The current Operator of Record route displays labels for **Lease Type**, **Operator No**, **District**, and **Prod Month**. The visible Lease Type choices include **Oil Lease**, **Gas Well**, and **Oil & Gas**. Copy only what the source displays at access time; interface labels, defaults, choices, and validation rules can change.

For every criterion used, preserve:

- exact source label;
- displayed default or choice when relevant;
- whether the preparer changed it;
- controlled reference to the actual value;
- action taken immediately before the recorded state; and
- retained-evidence reference for that state.

Use public placeholders such as `[controlled lease type]`, `[controlled operator number]`, `[controlled district]`, `[controlled production month]`, and `[controlled evidence reference]`. Do not publish an actual operator number, search input, result row, company name, production figure, screenshot, property identifier, owner record, account detail, private correspondence, credential, or session value in a reusable worksheet.

## Preserve the displayed route scope

The current Production Report Queries application says the Operator of Record path returns results only for reports filed after **February 11, 2005**. It also notes that some reports posted on Commission records may not be immediately available through the query because of internal processing. Record those statements as source-scope observations, not as promises of completeness.

The application points readers to the Production Data Query system for production data filed from **January 1993 through the last completed production month**. The RRC [Oil and Gas Production Data](https://www.rrc.texas.gov/oil-and-gas/research-and-statistics/production-data/) page lists PR and PDQ as separate production-query resources and describes the underlying production information as reported to the Commission by Texas operators.

Do not insert PDQ output into this worksheet. If a different time window or source is needed, open a separately named retrieval record with its own route, purpose, inputs, timestamp, evidence, limits, and outcome. A pointer to another system is not evidence that the two outputs are interchangeable or complete for a private question.

## Capture the source state, not a conclusion

One attempt may display a route form, required-field message, validation state, result list, empty result, error, timeout, maintenance notice, or other access boundary. Describe only what appeared and what action immediately preceded it.

Neutral state phrases include:

- official Production Report Queries entry surface displayed;
- Production by Operator of Record path selected;
- Lease Type, Operator No, District, and Prod Month controls displayed;
- controlled criteria entered or selected;
- source validation or required-field message displayed;
- result page or result list displayed;
- controlled target displayed or not displayed;
- empty, error, timeout, unavailable, or access-boundary state displayed; or
- exact source state could not be verified.

A form that was never submitted is not a no-match. An empty result is not proof that no report or relationship exists. A displayed result is not proof that the named company is the current operator, that the record belongs to a property or owner, or that any production should be attributed to a private interest.

## Keep adjacent P-4 and production jobs separate

“As shown on RRC Form P-4” is part of the source's route label. This worksheet preserves that label; it does not interpret a P-4, reconstruct an operator history, verify authority, or decide which record controls.

The RRC [About Oil and Gas Data Queries](https://www.rrc.texas.gov/resource-center/research/research-queries/about-oil-gas-data-queries/) page explains that each query is one slice of the larger Oil and Gas System. Adjacent pages describe separate P-4 Gatherer/Purchaser and Organization P-5 jobs. Keep those systems out of this attempt. A separate query needs a separate evidence record.

The same boundary applies to Production by Lease, Production by Filing Operator, Production Data Query, New Lease IDs, proration, Wellbore, production-history analysis, payment reconciliation, valuation, and offer review. Similar labels do not authorize cross-system joins or a conclusion about the private world.

## Do not automate or bypass access states

This workflow is intentionally limited to one authorized manual attempt. It does not authorize scraping, scripted navigation, repeated automated polling, bulk retrieval, session manipulation, validation bypass, access-control evasion, or restricted-function discovery.

If the public source requires an unavailable capability, presents a material access boundary, or changes so the route cannot be reproduced, record **unverified**. Do not work around the condition merely to complete the worksheet. The source's current access behavior is part of the provenance record.

## Retain evidence without republishing it

The public worksheet should point to a controlled evidence location. A retained-evidence record can include:

- attempt ID and worksheet version;
- approved repository, evidence vault, or case-system location;
- capture, note, or result filename;
- capture timestamp and timezone;
- SHA-256 or another integrity reference;
- official URL and exact selected route;
- controlled criteria reference;
- displayed route-scope and limitation notes;
- access role and retention rule; and
- whether an authorized reviewer later repeated the attempt.

Keep actual search values, result pages, screenshots, company names, property identifiers, owner records, royalty records, correspondence, credentials, cookies, session data, and internal notes out of the public template. Share retained evidence only with authorized recipients through an approved channel for a stated purpose.

## Choose one bounded status

Close the attempt with exactly one status:

1. **Located:** the recorded route exposed the specific controlled target sought.
2. **Not located:** the recorded attempt did not expose that target using the stated route, criteria, source state, access time, and displayed route scope.
3. **Unverified:** the route, exact labels, controlled criteria, displayed state, retained evidence, historical-scope note, or source limitation was not captured well enough to reproduce the attempt.

`Located` does not authenticate a result or connect it to a private interest. `Not located` does not prove absence. `Unverified` is the correct status when the evidence trail or access state is incomplete.

End with one neutral next question. An authorized reviewer might repeat the same route with a corrected controlled criterion, preserve a changed source state, or open a separately named official source under a new attempt ID. Do not end with a production, operator, property, ownership, title, payment, acreage, tax, reserve, forecast, valuation, offer, legal, compliance, or transaction conclusion.

## Protect the owner's information

Real criteria, screenshots, property records, royalty records, correspondence, and results belong in access-controlled storage. Share only records you are authorized to provide, and state why each record is requested.

A provenance worksheet improves reproducibility; it does not make MRX a regulator, title examiner, attorney, accountant, engineer, appraiser, investment adviser, neutral fiduciary, or source of an operator-status determination.

## Final provenance check

Before closing the record, confirm that it preserves the official directory and application routes, exact **Production by Operator of Record (as shown on RRC Form P-4)** selection, exact visible criteria labels, access time and timezone, controlled criteria reference, displayed navigation or result state, post-February-11-2005 route note, PDQ pointer, retained evidence, source limitations, bounded status, and one neutral next question.

If any required item is missing, use **unverified**. Stop there. The next step may be another official-source retrieval or an appropriately scoped professional review. It is not a production, operator, property, ownership, title, payment, acreage, tax, reserve, forecast, valuation, offer, legal, compliance, or transaction decision.
