> **Public-record retrieval boundary.** This article records one Texas RRC Underground Injection Control (UIC) / Injection-Storage Permit Query attempt. It does not interpret a result, well, operator, district, identifier, field, county, date, link, document, or source context. It does not establish property connection, title, ownership, acreage, tract or unit inclusion, lease effect, payee status, royalty share, decimal, payment responsibility, entitlement, permit compliance, operating condition, injection activity, production, cash flow, value, price, offer quality, or a transaction result. It does not provide legal, title, land, tax, accounting, appraisal, engineering, geological, environmental, regulatory, or financial advice. MRX may have an economic interest in a later transaction; when that applies, the buyer relationship is disclosed in writing before an agreement is signed.

A **Texas RRC injection-storage permit query retrieval** worksheet answers one narrow question: exactly how was one official UIC query attempted? Record the entry route, source-displayed criteria, navigation steps, query-page state, retained reference, access timestamp, source limitation, and one bounded retrieval status.

Use only **located**, **not located**, or **unverified**. Those terms describe the attempt, not whether a record is complete, current, applicable, or connected to private property. They do not decide regulatory standing, a lease, operating activity, production, payment, value, or transaction outcome.

## Start with the named official route

The Railroad Commission of Texas [Research Queries](https://www.rrc.texas.gov/resource-center/research/research-queries/) directory provides the agency's public-research context. The [Oil & Gas Data Query main page](https://webapps2.rrc.texas.gov/EWA/ewaMain.do) names **Injection-Storage Permit Query** among separate query routes. Preserve both complete addresses instead of recording a generic phrase such as “RRC injection search.”

The RRC's [About Oil & Gas Data Queries](https://www.rrc.texas.gov/resource-center/research/research-queries/about-oil-gas-data-queries/) page describes an Underground Injection Control (UIC) query as its own public query slice. The agency's [Injection-Storage Resources](https://www.rrc.texas.gov/oil-and-gas/applications-and-permits/injection-storage-permits/resources/) page separately identifies the Injection-Storage Permit Query among official query resources. The current [Underground Injection Control Query](https://webapps2.rrc.texas.gov/EWA/uicQueryAction.do) screen and [UIC Query How To](https://webapps2.rrc.texas.gov/EWA/help/UICGeneralHowTo.html) give the source-displayed query and help context. Preserve route identity and access time; a route name or visible screen label is not a conclusion about any particular record.

This worksheet owns one UIC / Injection-Storage Permit Query attempt. It does not merge that route with a Wellbore, production, Oil Proration, Gas Proration, Inactive Well, H-10, Organization, P-4, drilling-permit, pooling-filing, or private lease-review route. For broader orientation, use [Texas Railroad Commission: How to Use Public Records to Understand Your Mineral Rights](/blog/texas-railroad-commission-how-to-use-public-records-to-understand-your-mineral-rights/).

## Create an attempt header before searching

Give the attempt a neutral ID such as `TX-UIC-RET-01`. The ID labels a query session, not a property, well, field, operator, finding, or transaction conclusion. Record the purpose, official entry routes, query-page label, access date and time, timezone, preparer role, worksheet version, and any source-stated coverage, update, access, or display note.

Create a new attempt for a rerun. Do not overwrite a prior criteria snapshot or query-page state merely because the page, date, or displayed data changed. A later reviewer can compare attempts without treating either as a conclusion about a particular private interest.

## Capture each used criterion by its displayed label

The current [UIC query screen](https://webapps2.rrc.texas.gov/EWA/uicQueryAction.do) displays a well-type choice and criteria labeled **District**, **Oil Lease No./Gas Well ID No.**, **County**, **Field(s)**, **Operator(s)**, **UIC No.**, **Original Authority Date**, **API Unique No.**, **Top Injection Zone Depth**, **Bottom Injection Zone Depth**, **H-1 No.**, **W-14 No.**, **H-10 Status**, **Permitted Fluid**, **Injection Type**, **Special Conditions**, and **Formation Name**. The screen also states that H-1 and W-14 numbers cannot be entered together. The official help describes search and result-navigation context. Preserve the exact screen wording shown during the attempt rather than relying on memory.

Each criterion is a locator field, not a conclusion. For every field used, record the displayed label, entry method, controlled value reference, format shown by the source, whether it was submitted, and any displayed default, constraint, or warning. If a control was not used, record “unused.” Do not publish real identifier values in a reusable example.

## Record the navigation that actually occurred

After submitting criteria, preserve only the route that occurred:

**official directory → Oil & Gas Data Query main page → Injection-Storage Permit Query → criteria submitted → query-page state → displayed link or next route**

For each step, record the displayed page or link label, controlled route reference, action taken, access time and timezone, whether the page loaded or changed, and the next step selected. If the session ended, showed no rows, reached a stated result limit, or a stated constraint prevented submission, preserve that event and use **not located** or **unverified** only for the narrow retrieval fact.

The [UIC Query How To](https://webapps2.rrc.texas.gov/EWA/help/UICGeneralHowTo.html) identifies search and detail-navigation context. That identifies an information path; it does not establish the meaning, accuracy, completeness, legal effect, operating condition, permit compliance, activity, production status, or property connection of an individual result.

## Keep query state and downstream meaning separate

Record the query-page state separately from individual rows: criteria echoed by the page, any displayed count or range, displayed sort and page state, page access time, and a displayed message or source note. Then preserve only labels actually observed. Matching text or numbers are not a property connection and do not establish title, production, compliance, activity, value, payment, or lease facts.

If a page exposes a detail link, help page, document, or another official record channel, create a separate retrieval step. Record its originating attempt ID, link label, destination route, destination page label, new fields displayed, access timestamp, controlled retained-reference location, and located/not located/unverified status. The [Texas RRC Wellbore Query Retrieval Provenance Worksheet](/blog/texas-rrc-wellbore-query-retrieval-provenance-worksheet/) and [Texas RRC Drilling-Permit Query Retrieval Provenance Worksheet](/blog/texas-rrc-drilling-permit-query-retrieval-provenance-worksheet/) own different routes; preserve those boundaries even if screens display similar labels.

## Use only bounded retrieval statuses

- **Located:** the recorded official query exposed an identified result reference.
- **Not located:** the recorded attempt did not expose the sought result.
- **Unverified:** a label, identifier, route, or result appeared, but the narrow retrieval fact or relationship was not established.

Located does not mean connected, applicable, complete, accurate, current, compliant, active, productive, paid, valuable, or legally effective. Not located does not mean nonexistent. Unverified preserves uncertainty without alleging an error, defect, or violation.

## Final quality check

Before closing the worksheet, confirm that the exact official entry routes are named; every submitted criterion retains its source label and controlled value; any instruction, source context, or limitation is captured as shown; the navigation path records only steps that occurred; each status is only located, not located, or unverified; and no row interprets a result, identifier, well, field, operator, date, link, or property relationship.

A strong provenance worksheet is narrow by design. It lets an authorized reviewer understand and repeat the recorded UIC / Injection-Storage Permit Query attempt. It does not decide what any result means.
