> **Locator boundary.** This article explains how to point a reviewer to one unanswered question inside an existing mineral-rights worksheet. It does not identify an error, request a correction, validate a source, change an input or formula, calculate or certify value, establish ownership or title, analyze an offer, or recommend a transaction. MRX may have an economic interest in a later transaction; when that applies, the buyer relationship is disclosed in writing before an agreement is signed.

A **mineral rights worksheet question locator** is a small routing table, not a new analysis. Name the exact file you reviewed, preserve the version or date displayed, identify the tab or page and visible location, copy any source reference exactly as shown, and write one neutral unanswered question. If the worksheet already shows a reviewer or queue, record that handoff; otherwise leave it unresolved.

The locator's only outcome is findability. It helps another person open the same worksheet and reach the same displayed item without guessing which file, tab, row, or field you meant.

## Start with one locator row

Use these fields:

| Field                      | What to record                                                                                       |
| -------------------------- | ---------------------------------------------------------------------------------------------------- |
| Locator ID                 | A stable neutral row label, such as `Q-001`                                                          |
| Reviewed file              | The file title exactly as displayed                                                                  |
| Displayed version or date  | The received, reviewed, revision, or issue date shown in the file, if any                            |
| Tab, page, or section      | The visible worksheet tab, PDF page, or named section                                                |
| Exact location             | A visible cell, range, row/column, table row, field label, or other precise location                 |
| Displayed label            | The field or heading text exactly as shown                                                           |
| Displayed source reference | Any source name, link, record ID, or citation already printed beside the item; otherwise `not shown` |
| Unanswered question        | One short neutral question about the displayed item                                                  |
| Handoff                    | The reviewer, contact, or queue already shown in the worksheet; otherwise `unresolved`               |

Do not add a proposed value, corrected number, replacement source, error label, priority score, probability, decision, or recommendation. Those additions turn the row into a different work product.

## Identify the reviewed file before the question

Two files with similar names can contain different assumptions, formulas, dates, or outputs. Start by copying the complete displayed file title. Add the received or reviewed version/date only when it appears in or alongside the file. Do not invent a version number because a filename contains words such as “final,” “new,” or “revised.”

The [National Archives metadata guidance](https://www.archives.gov/records-mgmt/bulletins/2015/2015-01-appendix-a.html) identifies fields such as file name, record identifier, title, and creation date in its federal-records context. A private mineral-rights worksheet is not made subject to that federal guidance by this article. The useful general principle is narrower: record enough displayed identity information for another reviewer to retrieve the same item.

If the file has no visible version or date, write `not shown`. That is more accurate than substituting a download date, email date, local modified date, or guess.

## Point to the visible worksheet location

Next, record the worksheet tab, page, or section. Within that area, use the most precise visible location available:

- a cell such as `B2`;
- a range such as `A1:F4`;
- a row and displayed field label;
- a table name and row label;
- a PDF page and heading; or
- a screenshot region only when the underlying file offers no stable textual location.

Microsoft's [overview of formulas in Excel](https://support.microsoft.com/en-us/Excel/get-started/overview-of-formulas-in-excel) explains that a reference identifies a cell or range and that Excel uses A1 and R1C1 reference styles. Copy the reference style already visible in the workbook. A location reference says where to look; it does not prove that the cell, formula, input, or output is correct.

When a merged cell, hidden row, protected sheet, named range, or software-generated table makes the location unclear, record the nearest visible label and leave a question about the location itself. Do not unhide, unlock, rename, recalculate, or restructure the worksheet as part of this locator.

## Copy the source reference without judging it

Some worksheets display a source beside an input or finding. Copy only what appears: the agency or record name, link, query label, identifier, period, or access date. If no source is displayed, write `not shown`. Do not add a source from memory and do not label the displayed source authoritative, complete, matched, stale, controlling, or wrong.

This boundary matters with public oil-and-gas data. The [Railroad Commission of Texas research-query directory](https://www.rrc.texas.gov/resource-center/research/research-queries/) lists separate systems for permits, well records, production, organizations, GIS, and other subjects, with different update frequencies. The Commission also states that its online query data sets are informational, continually updated, and not authoritative public records. A locator should therefore preserve the exact query or record reference shown instead of reducing it to “RRC data.”

The Commission's [Production Data Query System FAQs](https://www.rrc.texas.gov/about-us/faqs/oil-gas-faq/production-data-query-system-faqs/) add context that can affect a question's location and wording: PDQ uses query-path navigation, reports production at the lease level, updates monthly, includes a reporting lag, and can change as revised or delinquent reports arrive. Recording the visible lease, field, operator, district, county, period, or query-path reference helps a reviewer find the displayed item. It does not establish that the public record matches a private interest.

If the source reference is incomplete, the neutral locator question can ask which displayed record or period the worksheet used. It cannot declare the worksheet unsupported or supply a replacement record. For source-origin or AI-support classification, use the separate [AI source-trace guide](/blog/mineral-rights-ai-source-trace/).

## Write one neutral unanswered question

Phrase the question so it can be answered by looking at the identified item. Good patterns include:

- “Which displayed source reference supports this field?”
- “Which worksheet date applies to this row?”
- “Does this label refer to the cell or the entire range shown?”
- “Which already-listed reviewer or queue owns this question?”

Avoid conclusions disguised as questions, such as “Why is this number wrong?” or “Why was the correct source ignored?” Those statements assert an error before the locator has established one. Also avoid compound questions that ask about the source, formula, title, value, and transaction at once. Split distinct questions into distinct rows.

Do not rewrite the worksheet language inside the question. Quote only the short displayed label needed to locate the item, and keep owner names, contact details, account numbers, tax identifiers, signatures, payment information, and other sensitive material out of a shared locator unless an authorized secure workflow specifically requires them.

## Route the question without assigning a new owner

Record a handoff recipient only when the worksheet, review cover note, or existing workflow already names that person, role, or queue. If no recipient is shown, write `unresolved`. The locator does not appoint a reviewer or decide whether the question belongs to an attorney, accountant, engineer, title professional, payor, operator, appraiser, or buyer.

The [underwriter-review process guide](/blog/what-to-expect-during-the-underwriter-review-process-for-your-mineral-rights/) explains the broader intake, document-matching, assumption, findings, and owner-next-step workflow. Keep that larger process separate. The locator has one narrower purpose: get one unanswered question to the exact worksheet location a reviewer needs.

## Know when the locator must stop

Stop and create a different work product when the next step would:

- assert that an input, formula, record match, or result is wrong;
- propose replacement text, a new input, or a corrected value;
- attach evidence to support a factual change;
- classify whether AI output is sourced, inferred, or unsupported;
- inventory an entire document package;
- record a decision, status, accountable owner, or next action;
- calculate or compare worksheet outputs;
- establish ownership, title, acreage, decimal, lease terms, payment entitlement, or value; or
- analyze an offer or recommend a transaction.

An asserted factual discrepancy belongs in the [valuation-input correction packet](/blog/mineral-rights-valuation-input-correction-packet/). Package-level file control belongs in the [sale document package index](/blog/how-to-build-a-mineral-rights-sale-document-package-index/). Dated decisions and next actions belong in the [sale decision log](/blog/mineral-rights-sale-decision-log/). Keeping these jobs separate prevents a simple locator row from becoming an unsupported conclusion.

## Review the completed locator

Before sending it, confirm that every row:

- names one exact reviewed file;
- records only a displayed version or date, or says `not shown`;
- identifies one tab, page, section, cell, range, row, or field;
- copies the displayed label and source reference without reinterpretation;
- contains one neutral unanswered question;
- uses an already-shown handoff or leaves it unresolved;
- leaves the worksheet, formulas, inputs, outputs, and evidence unchanged; and
- contains no correction, source judgment, appraisal, prediction, offer analysis, or recommendation.

The completed locator can shorten the time a reviewer spends searching for context. It cannot make the answer correct, prove a public-record match, validate a model, resolve title, establish value, or decide what an owner should do.
