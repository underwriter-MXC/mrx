> **Public retrieval boundary.** This article records one authorized manual attempt through the Texas Railroad Commission's **Search Injection/Disposal Permit Application Documents** route in the Electronic Document Management System. It does not determine a well status, permit validity, approval effect, compliance result, safety condition, environmental condition, property connection, ownership, title, payment, acreage, production, reserve, value, offer quality, legal effect, or transaction outcome. It does not provide legal, title, land, regulatory, environmental, engineering, tax, accounting, appraisal, investment, or financial advice. MRX may have an economic interest in a later transaction; when that applies, the buyer relationship is disclosed in writing before an agreement is signed.

A **Texas RRC EDMS injection disposal permit document retrieval** worksheet preserves how one manual search attempt was made. Its job is administrative: identify the official entry route, retain the exact source labels used, record a controlled criteria reference, timestamp the attempt, preserve what the application displayed, attach source-coverage notes, and give the attempt one bounded outcome.

Use only **located**, **not located**, or **unverified**. Those terms describe the attempt. They do not turn a source screen or document image into a conclusion about a permit, well, property, owner, regulator finding, or transaction.

## Start at the named EDMS route

Begin with the Texas RRC [Research Queries](https://www.rrc.texas.gov/resource-center/research/research-queries/) directory. The directory separately lists the **Electronic Document Management System** and currently labels it as updated nightly. Record the directory URL, directory label, access time, and the launched application URL before entering criteria.

The directory warns that automated retrieval of volumes of query data can degrade RRC systems and may end a session. It also describes online query data as informational, continually updated, non-authoritative, and without legal force or effect. This worksheet is therefore limited to one authorized manual attempt. It is not a scraping plan, monitoring workflow, bulk export process, or method for bypassing validation or access controls.

The launched [Electronic Document Search](https://webapps.rrc.texas.gov/eds/eds_searchUic.xhtml) application is visibly labeled **Search Injection/Disposal Permit Application Documents**. If that label is missing, renamed, redirected, or replaced by another record system, stop and use **unverified**. Do not silently substitute a nearby query because it contains a similar permit, well, operator, or document label.

## Keep EDMS separate from adjacent RRC systems

The RRC [Electronic Document Management System overview](https://www.rrc.texas.gov/resource-center/research/research-queries/about-edms/) identifies several related record families and routes. They are not interchangeable.

| Source route | What this worksheet does |
|---|---|
| EDMS Search Injection/Disposal Permit Application Documents | Records one manual search attempt for displayed application-document material. |
| Injection & Disposal or Injection-Storage Permit Query | Keep separate; it is a data-query route, not this EDMS document-search attempt. |
| Oil & Gas Imaged Records | Keep separate; approved application files, hearing records, and other imaged-record classes follow their own source routes and coverage. |
| H-9, H-10, completions, drilling permits, production, or wellbore queries | Keep separate; each has different criteria, source state, record family, and limitations. |

The [About Oil and Gas Data Queries](https://www.rrc.texas.gov/resource-center/research/research-queries/about-oil-gas-data-queries/) page supplies additional evidence that the Injection-Storage Permit Query is separately routed. A link between systems is a navigation clue, not permission to merge their evidence or conclusions.

## Create the attempt header before entering criteria

Assign a neutral attempt ID that reveals no private property, party, or transaction detail. Then record:

- the official directory URL and EDMS application URL;
- the source-displayed route label;
- access date, clock time, and explicit timezone;
- browser or session reference needed to reproduce the observation;
- authorized requester or custodian role, if an internal record requires it;
- a controlled criteria-set reference rather than the actual sensitive values;
- an evidence destination and retention reference; and
- a field for validation, result, completed-empty, error, timeout, or access state.

Do not publish tracking numbers, permit numbers, operator identifiers, field identifiers, lease identifiers, API numbers, well numbers, names, dates, or document images merely because the application displays them. Keep sensitive or unnecessary criteria in an authorized controlled location and use the worksheet to point to that record.

## Preserve the source-displayed search mechanics

The current application says that an application must contain **all** entered search criteria to appear in the results list. It also supplies route-specific instructions:

- use **Tracking Number** to search for a specific permit application;
- use **Operator Number**, **Field Number**, or **Oil Lease No./Gas ID** to search for a list of permit applications; or
- enter at least three other search criteria for a list search.

Those are source-displayed mechanics, not recommendations about which criteria identify a property or establish a relationship. Record only the labels actually used in the attempt. Current visible labels include:

- **Tracking Number**;
- **Group Results By**;
- **Permit Number**;
- **Document Type**;
- **Field Name** and **Field Number**;
- **Operator Name** and **Operator Number**;
- **Lease Name** and **Oil Lease No./Gas ID**;
- **District** and **County**; and
- **RRC Stamp Date From** and **RRC Stamp Date To**.

The date controls specify an `mm/dd/yyyy` input format. Preserve that source format if a date criterion is used. Do not rewrite a source label into broader regulatory terminology, and do not treat a successful validation as proof that the criteria identify the intended private interest.

The application notes that **Operator Name** and **Operator Number** refer to the operator that filed the permit application. That statement does not establish who currently operates a property, who owns a mineral interest, or whether any displayed application relates to the reader.

## Distinguish the default screen from a completed empty result

The application can show zero applications and a **No results found for search** message in its initial screen state. That default display is not evidence that valid criteria were submitted. It cannot support **not located**.

Use the following state rules:

| Displayed state | Worksheet outcome | What to preserve |
|---|---|---|
| Initial or default zero-result screen before a completed search | **unverified** | Route, access time, and evidence that no completed attempt is established. |
| Validation message or rejected criteria | **unverified** | Exact message, labels involved, timestamp, and retained reference. |
| Accepted criteria followed by a completed empty result attributable to the attempt | **not located** | Criteria-set reference, completed state, timestamp, and evidence reference. |
| Responsive application or document material displayed after an accepted search | **located** | Result-list state, document-list state if opened, timestamp, and evidence reference. |
| Error, timeout, interrupted navigation, access restriction, session termination, or unclear state | **unverified** | Exact displayed state and where the attempt stopped. |

Do not retry until a preferred answer appears. If an authorized correction is necessary, start a new attempt ID or record a clearly linked correction event. Preserve the original state instead of overwriting it.

## Record result and document-list fields without interpreting them

The current application exposes application-result fields that include **District**, **County**, **Field Name**, **Field Number**, **Lease Name**, **Operator Name**, **Tracking Number**, **Permit Number**, **RRC Stamp Date**, and **Document Count**. Its document-list surface includes fields such as **District**, **County**, **Field Name**, **Lease Name**, **Operator Name**, **API Number**, **Well Number**, **RRC Stamp Date**, **Document Type**, and **View**.

Record which labels appeared and where the retained evidence is stored. Do not copy the public values into the worksheet unless they are necessary, authorized, and suitable for the worksheet's audience. A displayed row does not establish:

- that a permit is current, valid, effective, or applicable to a private interest;
- that a displayed operator is the current operator of a property;
- that a well, field, lease, district, county, or document belongs to the reader;
- that an application category is an independently verified compliance conclusion;
- that every relevant document is available, current, complete, or correctly linked; or
- that a permit-document record determines safety, environmental condition, production, ownership, payment, value, legal position, or a transaction decision.

If a result opens a document view, preserve the navigation sequence as separate evidence:

`official EDMS entry → labels used → accepted search state → application result list → document list → displayed view route`

Do not describe a view as a signed permit, final approval, hearing record, pressure test, or other document class unless the source itself displays that identity and the evidence record retains it.

## Attach coverage and availability notes

The RRC EDMS overview says the revised search provides access to images of **Form H-1, H-1A, and W-14** applications and correspondence for injection or disposal wells. It describes applications beginning with **September 2000** as available and identifies source-displayed application categories including in-process, approved, administratively denied, withdrawn, and returned.

Treat those statements as source coverage, availability, and terminology notes. Do not convert them into a current permit-status conclusion. The same page says that after an approved permit is signed, documentation associated with the application file is imaged and made available after a stated delay. Preserve the source wording and access date; do not infer that a missing image means an approval, application, or document does not exist.

The overview also discusses older **Form H-5** pressure-test images and points to other imaged-record routes for different periods or record families. Those materials remain outside this attempt. If they become relevant, create a new source-specific record rather than broadening the EDMS application-document attempt after the fact.

## Add a source-to-recipient transfer note

An evidence record can lose its limits when it moves to another person or system. Attach a transfer note that includes:

- attempt ID and exact source route;
- access time and timezone;
- controlled criteria-set reference;
- displayed state and bounded outcome;
- retained evidence reference and any access restriction;
- source coverage and availability notes;
- unresolved validation, identity, or completeness questions; and
- a reminder to recheck currency, completeness, accuracy, and suitability before reuse.

The recipient should not inherit an unstated assumption that **located** means verified, that **not located** means nonexistent, or that **unverified** means adverse. Each term remains tied to one attempt, one route, one criteria set, and one source state.

## Copyable worksheet structure

Use a structure like this in an authorized record:

| Field | Entry |
|---|---|
| Attempt ID | Neutral internal ID |
| Official directory route | URL and source label |
| EDMS application route | URL and exact displayed route label |
| Access timestamp | Date, time, and timezone |
| Criteria labels used | Exact labels only |
| Controlled criteria reference | Authorized location; do not expose unnecessary values |
| Submission state | Not started, validation, accepted, error, timeout, access restriction, or interrupted |
| Displayed result state | Default, result list, completed empty, document list, or unclear |
| Bounded outcome | Located, not located, or unverified |
| Retained evidence reference | Screenshot, export, note, or controlled file reference |
| Coverage note | Forms, period, availability, and source-access date |
| Adjacent routes excluded | Separate systems not searched under this attempt |
| Transfer note | Recipient, limits, unresolved questions, and recheck requirement |

## Final quality check

Before closing the worksheet, confirm that:

- the attempt used only the named EDMS application-document route;
- the default screen was not mislabeled as a completed empty search;
- every used criterion is recorded by its exact displayed label;
- actual values remain controlled and are not unnecessarily published;
- the timestamp includes a timezone;
- the retained evidence matches the recorded state;
- source coverage and transfer notes are attached;
- no adjacent RRC system was merged into the attempt;
- no automation, bulk retrieval, repeated-query workflow, bypass, or workaround occurred; and
- the outcome vocabulary is limited to **located**, **not located**, or **unverified**.

If any item fails, keep the attempt **unverified**. The purpose of the worksheet is to preserve what happened, including an incomplete or inconclusive attempt, without turning a retrieval event into a permit, property, compliance, legal, value, offer, or transaction conclusion.
