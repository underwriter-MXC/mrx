> **Public-record retrieval boundary.** This article records one Texas RRC Inactive Well Aging Report query attempt. It does not interpret an inactivity type, inactive period, result, extension, cost field, compliance date, renewal label, operator, API number, lease, well, county, field, location, plugging field, completion date, or source limitation. It does not establish property connection, title, ownership, acreage, lease effect, operator or well status, compliance, financial assurance, plugging duty, production, cash flow, value, offer quality, legal effect, or a transaction result. It does not provide legal, title, land, tax, accounting, appraisal, engineering, geological, environmental, regulatory, or financial advice. MRX may have an economic interest in a later transaction; when that applies, the buyer relationship is disclosed in writing before an agreement is signed.

A **Texas RRC Inactive Well Aging Report retrieval** worksheet answers one narrow question: exactly how was one official IWAR query attempt performed? Record the official entry route, every source-displayed page label, access timestamp and timezone, selected inactivity type, other controlled criteria, navigation or result state, authorized retained reference, source limitations, and one bounded retrieval status.

Use only **located**, **not located**, or **unverified**. Those words describe the retrieval attempt. They do not decide whether a well has a particular inactive period, whether an operator or well is compliant, whether a P-5 renewal or plugging extension has a particular status, or whether a displayed record applies to a private mineral interest.

## Start with the exact IWAR route

The Railroad Commission of Texas [Research Queries](https://www.rrc.texas.gov/resource-center/research/research-queries/) directory lists **Inactive Well Aging Report Query** as an Oil & Gas route. The official [Oil & Gas Data Query menu](https://webapps2.rrc.texas.gov/EWA/ewaMain.do) lists that query separately from **P-5 Renewal Status Query** and **Inactive Well Query**. Preserve the full directory and menu routes instead of reducing all three to a generic phrase such as `RRC inactive-well search`.

The launched [Inactive Well Aging Report Query](https://webapps2.rrc.texas.gov/EWA/inactiveWellQueryAction.do) uses the route `inactiveWellQueryAction.do`. The general Inactive Well Query uses the separate `inactiveWellAllQueryAction.do` route. A shared operator, district, lease, field, county, API, or well label does not merge those two query systems or prove that their returned information has the same scope, timing, meaning, or private-property relationship.

For broader source orientation, use [Texas Railroad Commission: How to Use Public Records to Understand Your Mineral Rights](/blog/texas-railroad-commission-how-to-use-public-records-to-understand-your-mineral-rights/). For the other route's attempt-level documentation, use the [Texas RRC Inactive Well Query Retrieval Provenance Worksheet](/blog/texas-rrc-inactive-well-query-retrieval-provenance-worksheet/). Do not combine the two worksheets.

## Preserve the current page-label mismatch

The launched application's visible body currently says **Inactive Well Aging Report (IWAR) Query**, while its HTML title says **P-5 Renewal Status Query**. Record both labels with the route, access time, and source context in which each appeared. Do not silently correct one label, collapse them into a new label, or use the mismatch to infer a data error, record class, renewal condition, compliance state, or legal effect.

The provenance record may state only what was displayed: the official directory and menu named an Inactive Well Aging Report Query, the launched application's body used the IWAR wording, and the page title exposed different wording at the recorded time. If a later attempt displays different labels, create a new attempt record rather than overwriting the first one.

## Create an attempt header before entering criteria

Give the attempt a neutral ID such as `TX-IWAR-RET-01`. That identifier labels a retrieval session, not a well, operator, report, violation, property, mineral interest, finding, or transaction. Record:

- the official directory route and exact directory label;
- the Oil & Gas Data Query menu route and exact menu label;
- the launched application route, body label, and page-title label;
- access date, time, and timezone;
- preparer role and worksheet version;
- stated purpose, limited to IWAR retrieval;
- source-stated update, access, display, search, download, and result limitations; and
- the controlled location where real criteria and retained evidence will be stored.

Create a new attempt ID for every rerun. Do not replace an earlier query record because a label, criterion, result, page state, help screen, or access condition changed.

## Capture the selected inactivity type exactly

The current application displays an **Inactivity Type** selector. Its options distinguish all inactive wells from wells displayed in five-year-or-more and ten-year-or-more groupings, and distinguish a current-date reference from a next-P-5-renewal reference. Preserve the exact option selected as displayed during the attempt. Do not shorten it to `5 years`, `10 years`, `current`, or `renewal` because that removes part of the source label.

The [IWAR Query How To](https://webapps2.rrc.texas.gov/EWA/help/IWAR_HowTo.html) describes an operator-and-inactivity-type route and a separate other-criteria route. It also states that an other-criteria search defaults to an all-inactive-wells/current-date inactivity type. Record whether a value was selected by the user or appeared as the source's default. A default is still part of the attempt's provenance; it is not a conclusion about a well.

## Preserve other criteria without publishing them

The current IWAR application exposes operator selection plus other source-displayed criteria, including oil or gas well type, district, lease or gas-well identifier, county, field, and API-number entry. The official How To page also describes separate operator, lease, and field search steps. Record only the criteria actually used, the exact labels shown, whether a value was entered or selected, and the controlled reference where the value is retained.

Do not populate a reusable public example with a real operator name or number, API number, district, lease number, gas-well ID, county, field, or result. A criteria value is a locator input. It does not prove that a returned operator, lease, well, field, county, or property is connected to the mineral interest being researched.

If the user opened an operator, lease, or field selector, preserve that navigation as its own step. Record the displayed search mode, the controlled criterion, the selected row reference, the return path, and the time. Do not treat a selection list as a substantive IWAR result.

## Record the navigation that actually occurred

Preserve the route as a sequence:

**Research Queries directory → Oil & Gas Data Query menu → Inactive Well Aging Report Query → selected inactivity type and controlled criteria → displayed validation, result, error, download, or next-navigation state**

For each step, record the complete controlled route reference, exact displayed label, action taken, access time and timezone, whether the page loaded or changed, and the next step selected. If a session ended, a constraint appeared, the page did not expose the narrow reference sought, or the attempted relationship remained unclear, use **not located** or **unverified**.

Do not extend that status to a well, operator, lease, field, property, mineral interest, report, renewal, extension, plugging matter, or compliance question.

## Treat result fields as displayed labels, not conclusions

The official [IWAR Query About](https://webapps2.rrc.texas.gov/EWA/help/IWAR_About.html) page describes categories that may appear in IWAR data, including API number, operator name, oil-or-gas designation, district, lease name and number, well number, county, field name, depth, location, shut-in date, inactivity, extension status, cost calculation, compliance date, plugged-well field, and original completion date. The page also states a monthly update schedule.

Those are source descriptions and field labels. This worksheet does not interpret an individual value, confirm that an update occurred, decide whether the displayed data are accurate or current, calculate inactivity, establish compliance, interpret an extension or cost field, or determine a plugging or renewal obligation.

The [IWAR results help](https://webapps2.rrc.texas.gov/EWA/help/IWAR_results_howto.html) describes search-criteria display, result columns, sorting, pagination, detail links, and a download option. Record only the result-page state and navigation that occurred: visible criteria header, displayed result range, sort or page state, link or download action, and controlled retained-reference location. A downloaded file becomes a separate retained artifact with its own filename, hash if used, access time, source label, and limitations.

## Preserve the official data limitation

The Research Queries directory states that online data sets are continually updated, provided for informational purposes, not intended as authoritative public records, and have no legal force or effect. It places responsibility on users to check accuracy, completeness, currency, and suitability. Preserve that limitation with the attempt.

A **located** IWAR reference cannot prove that the displayed inactive period, extension, compliance date, cost field, plugged-well field, operator, lease, well, location, or other value is complete, current, accurate, applicable to a private interest, or sufficient for a downstream decision. A **not located** attempt cannot prove that no IWAR record, inactive-well record, operator record, wellbore record, production record, or other official source exists.

## Keep neighboring systems separate

- The general **Inactive Well Query** uses a separate route and owns its own current-data retrieval attempt.
- The **P-5 Renewal Status Query** uses a separate route. The IWAR application's current HTML title does not authorize combining the two.
- The **Organization (P-5) Query** owns organization-record retrieval, not IWAR interpretation.
- The **Wellbore Query**, **H-10 Query**, proration queries, production systems, and Imaged Records each require separate attempt records.
- A lease, operator, API, field, county, well, or result label shared across screens does not establish that the records describe the same private mineral interest.

If another route is needed, create a separate attempt with its own purpose, source, criteria, time, status, retained reference, and limitation. Any later comparison is a separately scoped analysis, not part of this IWAR retrieval worksheet.

## Use only bounded retrieval statuses

- **Located:** the recorded official IWAR attempt exposed the identified result reference.
- **Not located:** the recorded attempt did not expose the result reference sought.
- **Unverified:** a route, label, result, download, detail link, or relationship appeared, but the narrow retrieval fact was not established.

Located does not mean inactive for a verified period, noncompliant, renewed, extended, plugged, producing, connected to a property, owned, leased, valuable, or legally effective. Not located does not mean nonexistent. Unverified preserves uncertainty without alleging an error, omission, defect, violation, or false record.

## Final retrieval check

Before closing the attempt, confirm that the worksheet preserves the complete official route, every exact source label, access time and timezone, selected inactivity type, controlled criteria, user-selected or default state, navigation that occurred, displayed result or error state, retained reference, source limitation, bounded status, and a neutral next question. If one item is missing, use **unverified** until the retrieval record is complete.

Stop there. The next step may be another official-source retrieval or an appropriately scoped professional review. It is not a conclusion about an inactive period, extension, renewal, operator or well status, compliance, plugging, production, property connection, title, ownership, acreage, legal effect, value, offer quality, or a transaction.
