> **Public-record retrieval boundary.** This article records one Texas RRC Severance Query retrieval attempt. It does not interpret a result, category, reason, letter date, schedule label, operator, district, lease number, well identifier, field, link, document, or source context. It does not establish severance status, legal effect, compliance, reconnection eligibility, production, property connection, title, ownership, acreage, tract or unit inclusion, lease effect, payee status, royalty share, decimal, payment responsibility, entitlement, cash flow, value, price, offer quality, or a transaction result. It does not provide legal, title, land, tax, accounting, appraisal, engineering, geological, environmental, regulatory, or financial advice. MRX may have an economic interest in a later transaction; when that applies, the buyer relationship is disclosed in writing before an agreement is signed.

A **Texas RRC severance query retrieval** worksheet answers one narrow question: exactly how was one official Severance Query attempted? Record the entry route, source-displayed criteria labels, controlled values, result and help navigation, retained reference, access timestamp, source limitation, and one bounded retrieval status.

Use only **located**, **not located**, or **unverified**. Those terms describe the retrieval attempt, not whether a displayed record is complete, current, applicable, or connected to private property. They do not decide compliance, reconnection, production, payment, value, or a transaction outcome.

## Start with the named official route

The Railroad Commission of Texas [Research Queries](https://www.rrc.texas.gov/resource-center/research/research-queries/) directory supplies the agency's public-query context. The [Oil & Gas Data Query main page](https://webapps2.rrc.texas.gov/EWA/ewaMain.do) names **Severance Query** among separate query routes. Preserve both complete addresses instead of writing only “RRC lookup.”

The RRC's [About Oil & Gas Data Queries](https://www.rrc.texas.gov/resource-center/research/research-queries/about-oil-gas-data-queries/) page identifies Severance Query as a distinct public query slice. The current [Severance Query](https://webapps2.rrc.texas.gov/EWA/severanceQueryAction.do), [help contents](https://webapps2.rrc.texas.gov/EWA/help/Severance_TOC.html), and [How To](https://webapps2.rrc.texas.gov/EWA/help/Severance_HowTo.html) pages supply the source-displayed query and help context. Preserve route identity and access time; a route name or visible screen label is not a conclusion about a particular record.

This worksheet owns one Severance Query attempt. It does not merge that route with a Wellbore, production, Oil Proration, Gas Proration, Inactive Well, H-10, Organization, P-4, drilling-permit, pooling-filing, Injection-Storage, or private lease-review route. For broader orientation, use [Texas Railroad Commission: How to Use Public Records to Understand Your Mineral Rights](/blog/texas-railroad-commission-how-to-use-public-records-to-understand-your-mineral-rights/).

## Create an attempt header before searching

Give the attempt a neutral ID such as `TX-SEV-RET-01`. The ID labels a query session, not a property, lease, well, field, operator, finding, or transaction conclusion. Record the purpose, official entry routes, query-page label, access date and time, timezone, preparer role, worksheet version, and any source-stated coverage, update, access, display, or result-limit note.

Create a new attempt for a rerun. Do not overwrite a prior criteria snapshot or query-page state merely because the page, date, or displayed data changed. A later reviewer can compare attempts without treating either attempt as a conclusion about a private interest.

## Capture each used criterion by its displayed label

The current [Severance Query](https://webapps2.rrc.texas.gov/EWA/severanceQueryAction.do) displays an **Oil Wells**, **Gas Wells**, or **Both** choice and criteria labeled **District**, **Oil Lease No./Gas Well ID No.**, **Field(s)**, **Operator(s)**, **Severance/Seal Cert. Ltr. Issued By**, **Severance/Seal Cert. Ltr. Reason**, **Certified Letter Date**, **Severance/Seal Letter Date**, and **Severance/Seal Category**. It also displays a separate **Current**, **Historical**, or **Both** choice. Preserve the exact wording shown during the attempt instead of reconstructing labels from memory.

Each field is a locator, filter, or source-displayed category, not a conclusion. For every field used, record the displayed label, entry method, controlled value reference, format shown by the source, whether it was submitted, and any visible default, constraint, or warning. Record “unused” for fields not used. Keep actual lease, well, operator, date, and letter values out of a reusable public example.

## Record only the navigation that occurred

Preserve the path as a sequence:

**official directory → Oil & Gas Data Query main page → Severance Query → criteria submitted → query-page state → displayed help, result, or next route**

For each step, record the displayed page or link label, controlled route reference, action taken, access time and timezone, whether the page loaded or changed, and the next step selected. If the session ended, exposed no requested reference, reached a source-stated limit, or a visible constraint prevented submission, preserve that event and use **not located** or **unverified** only for the narrow retrieval fact.

The [Severance Query How To](https://webapps2.rrc.texas.gov/EWA/help/Severance_HowTo.html) page identifies result columns labeled **Operator Number**, **Operator Name**, **District**, **Lease Number**, **Lease Name**, **Field Name**, and **Field Number**, and states a maximum of 10,000 records for a query result. Those are source labels and a source-stated interface limit. They do not establish the meaning, accuracy, completeness, legal effect, compliance status, production status, or property connection of an individual row.

## Keep query state, result rows, and process guidance separate

Record the query-page state separately from any row: criteria echoed by the page, a displayed count or range, sort and page state, page access time, and any displayed message or limitation. Then preserve only labels actually observed. Matching names, numbers, dates, or categories are not a property connection and do not establish title, production, compliance, value, payment, or lease facts.

If a page exposes a result link, help page, document, or another official record channel, create a separate retrieval step. Record its originating attempt ID, link label, destination route, destination page label, newly displayed fields, access timestamp, controlled retained-reference location, and located/not located/unverified status.

The RRC's [Severance/Reconnect Process](https://www.rrc.texas.gov/oil-and-gas/compliance-enforcement/severance-reconnect-process/) page is a separate explanatory source. A query row does not, by itself, decide how that process applies, whether a record is current, whether a requirement has been satisfied, or whether reconnection is available. Do not convert process guidance into a query-result conclusion.

## Use only bounded retrieval statuses

- **Located:** the recorded official query exposed an identified result reference.
- **Not located:** the recorded attempt did not expose the sought result reference.
- **Unverified:** a label, identifier, route, or result appeared, but the narrow retrieval fact or relationship was not established.

Located does not mean connected, applicable, complete, accurate, current, compliant, reconnected, active, productive, paid, valuable, or legally effective. Not located does not mean nonexistent. Unverified preserves uncertainty without alleging an error, defect, or violation.

## Turn gaps into neutral next questions

When the route or criteria do not expose a requested reference, ask a bounded retrieval question: Was the correct Oil Leases/Gas Wells/Both choice used? Was the displayed district or identifier format copied exactly? Was a filter omitted or applied? Did the page show a limit, warning, or access issue? Is a separate official route needed for a different record class?

Do not turn a gap into “no record exists,” “the property is clear,” “the well is compliant,” “the lease is producing,” or “the interest has no value.” Those are not retrieval statuses.

## Final quality check

Before closing the worksheet, confirm that the exact official entry routes are named; every submitted criterion retains its source label and controlled value; any instruction, source context, or limitation is captured as shown; the navigation path records only steps that occurred; query state, rows, help, and process guidance remain separate; each status is only located, not located, or unverified; and no row interprets a result, category, reason, date, operator, lease, well, field, link, or property relationship.

A strong provenance worksheet is narrow by design. It lets an authorized reviewer understand and repeat the recorded Severance Query attempt. It does not decide what any result means.
