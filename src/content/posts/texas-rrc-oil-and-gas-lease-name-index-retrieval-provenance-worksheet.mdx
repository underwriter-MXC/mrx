> **One-artifact locator boundary.** This article documents one manual retrieval attempt for exactly one Texas Railroad Commission Oil and Gas Lease Name Index PDF selected by source-displayed month, `Oil` or `Gas`, and RRC district. It does not automate, bulk retrieve, interpret, or join an index row to a private property. It does not determine current operator status, property connection, ownership, title, acreage, lease effect, royalty decimal, payment entitlement, production attribution, reserves, value, offer quality, compliance, legal or tax effect, or transaction action. It does not provide legal, title, land, regulatory, engineering, environmental, geological, tax, accounting, appraisal, investment, or financial advice. MRX may have an economic interest in a later transaction; when that applies, the buyer relationship is disclosed in writing before an agreement is signed.

A **Texas RRC Oil and Gas Lease Name Index retrieval** worksheet preserves one exact evidence path: source page, access time and timezone, page-updated date, displayed month, `Oil` or `Gas` selection, district, linked PDF artifact, access state, controlled search reference, retained-reference location, limitations, and only `located`, `not located`, or `unverified`.

The output is a locator provenance record. A displayed lease name, field name, organization name, oil lease number, or Gas ID is not proof that the row is current, complete, connected to a particular property, or relevant to a private mineral interest.

## Confirm that the Lease Name Index is the right source

The official [Oil and Gas Lease Name Index](https://www.rrc.texas.gov/oil-and-gas/research-and-statistics/well-information/oil-and-gas-lease-name-index/) page says the PDFs list Texas oil leases and gas wells by RRC district and then alphabetically by lease name. It says the indexes include field name, operator name, and oil lease or Gas ID number and are updated monthly.

Use this workflow only when the authorized job is to retrieve one of those page-linked monthly PDFs and preserve how the attempt occurred. The broader [Research and Statistics](https://www.rrc.texas.gov/oil-and-gas/research-and-statistics/) page lists the Lease Name Index under Well Information, separately from production data, proration schedules, well records, and other resources.

Do not use this worksheet for:

- a Production by Lease query;
- the New Lease IDs Built Query;
- a Wellbore Query or Public GIS Viewer search;
- a broad multi-route production-record locator;
- interpreting a row, comparing operators, or evaluating production; or
- deciding whether an offer, lease, title position, payment, or transaction is correct.

## Lock one month, record class, and district before opening a PDF

The source page organizes links under a displayed month, with separate `Gas` and `Oil` columns and district labels. Record all three selections before opening a PDF:

1. the month exactly as displayed on the source page;
2. either `Oil` or `Gas`, never both in one record; and
3. one district label exactly as displayed.

If any selection changes, start a new provenance record. Do not combine multiple months, both record classes, several districts, or several PDFs into one outcome. That separation prevents a later reader from guessing which artifact produced a note.

Record the source-page URL, access date, clock time, timezone, and the page's displayed last-updated date. A date inside the PDF and the page-updated date are different fields; preserve each only when the source displays it.

## Preserve the exact PDF artifact

Open the one selected link manually. Record the final PDF URL, source-displayed link context, filename when exposed, HTTP or viewer state, and access timestamp. If policy permits retaining the file, preserve it in an authorized controlled location and record a neutral retained-reference ID. Do not place a downloaded index containing real rows in a public repository or public worksheet.

One current page-linked [District 8 Oil Lease Name Index PDF](https://www.rrc.texas.gov/media/zpog0h1d/olm003_08_20260731_rrc021_sep2026.pdf) reviewed during source QA displayed an index date, `Oil Lease Name Index` label, district, and columns for lease name, field name, organization name, and lease number. That review supports the document-structure description only. This article publishes no row and does not treat any displayed name or number as property, ownership, status, production, value, or transaction evidence.

If the link fails, the browser blocks the file, the document is not a PDF, the expected district or record-class context cannot be confirmed, or the artifact changes during the attempt, record the exact state and use `unverified`. Do not substitute a nearby link or another RRC system without starting a separate record.

## Keep searched text and matches controlled

The public worksheet does not need an owner's lease name, operator, organization, ID, property, or matched row. Store the exact searched text and any match note under a controlled-reference ID. Preserve spelling, punctuation, spacing, and capitalization as entered or viewed; do not silently normalize them into a stronger identity claim.

If the PDF viewer supports a manual find operation, record the searched text by controlled reference and the viewer state. A text hit is `located` only within the selected artifact. It does not prove that similarly named rows are the same lease, that an organization is the current operator, or that the artifact connects to an owner's tract.

## Use only three bounded outcomes

Use one of these outcomes:

- **located:** the controlled searched text was visibly located in the one selected PDF during the recorded attempt;
- **not located:** the controlled searched text was not located in that one PDF during the recorded attempt; or
- **unverified:** access, artifact identity, viewer behavior, source context, or evidence capture was insufficient to support either of the other states.

Never shorten `not located` to `absent`, `does not exist`, or `no record`. A different month, Oil or Gas selection, district, spelling, artifact, or system may produce a different state. The worksheet documents one attempt, not the universe of Commission or private records.

## Keep the PDF index separate from online queries

The official [Research Queries](https://www.rrc.texas.gov/resource-center/research/research-queries/) directory lists distinct online systems and warns against automated volume retrieval. It also says the online-query data sets are informational, continually updated, non-authoritative, and without legal force.

The Lease Name Index page is a monthly PDF index route, not an online query. Do not relabel it as a query or import a result from Production by Lease, New Lease IDs Built, Wellbore, GIS, or another application into this record. This workflow independently prohibits scraping, automation, bulk collection, repeated retrieval, access-control bypass, and route substitution.

## Blank one-PDF provenance template

| Field                         | What to preserve                                                        |
| ----------------------------- | ----------------------------------------------------------------------- |
| Retrieval ID                  | Neutral identifier with no owner-specific locator                       |
| Source page                   | Exact Lease Name Index page URL                                         |
| Source accessed at            | Date, clock time, and explicit timezone                                 |
| Page updated date             | Exact source-displayed date or not displayed                            |
| Selected month                | One month exactly as displayed                                          |
| Record class                  | `Oil` or `Gas`                                                          |
| RRC district                  | One source-displayed district label                                     |
| PDF link context              | Month, record class, and district link selected                         |
| Final PDF URL or filename     | Exact artifact locator                                                  |
| Artifact accessed at          | Date, clock time, and explicit timezone                                 |
| Access state                  | Opened, HTTP error, viewer error, unexpected artifact, or unverified    |
| Controlled search reference   | Neutral pointer to exact searched text; no private value in public copy |
| Outcome                       | Located, not located, or unverified                                     |
| Controlled retained reference | Authorized location for retained file or capture, when permitted        |
| Limitations                   | One-artifact boundary and prohibited inferences                         |
| Handoff owner                 | Authorized next reviewer and narrow next task                           |

Keep the template blank until an authorized attempt supplies each field. Do not insert example lease names, organizations, IDs, properties, owners, matches, values, or conclusions that could be mistaken for evidence.

## Handoff without expanding the claim

A useful handoff lets the next authorized reviewer identify the exact source page, selected month, record class, district, PDF, access time, controlled search reference, retained artifact, attempt state, and limitations. It does not turn the index into a deed, operator-status certificate, division order, production report, royalty statement, appraisal, offer analysis, or legal conclusion.

If a later workflow needs to connect a locator lead to a property or private right, open a separately scoped evidence task with qualified review. Do not bridge that gap inside the Lease Name Index retrieval record.

The retrieval job is complete when one neutral provenance record preserves the exact route, artifact, controlled reference, bounded outcome, limitations, and responsible next owner. Interpretation and decision-making remain separate workflows.
