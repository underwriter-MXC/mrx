> **Public retrieval boundary.** This article records one authorized manual attempt through the Texas Railroad Commission's Imaged Records **Monthly Transportation and Storage Reports (Form T-1)** profile. It does not interpret a report or determine completeness, facility or operator identity, production, transportation, storage, inventory, compliance, property connection, ownership, title, lease, royalty, payment, acreage, value, offer quality, legal effect, tax, or transaction outcome. It does not provide legal, title, land, regulatory, geological, engineering, tax, accounting, appraisal, investment, or financial advice. MRX may have an economic interest in a later transaction; when that applies, the buyer relationship is disclosed in writing before an agreement is signed.

A **Texas RRC Form T-1 report retrieval** worksheet preserves how one manual source attempt occurred. It identifies the official route and profile, timestamps the attempt, records source-described coverage, points to controlled criteria, keeps access and result states separate, retains evidence, and assigns one bounded outcome.

Use only **located**, **not located**, or **unverified**. These labels describe one retrieval event. They do not turn a profile name, coverage statement, result row, document link, image, form, filing route, or empty state into a conclusion about a facility, operator, property, owner, lease, production, transportation, storage, inventory, royalty, valuation, offer, or transaction.

## Start with the official query directory

Open the Texas RRC [Research Queries](https://www.rrc.texas.gov/resource-center/research/research-queries/) directory and retain its current Oil and Gas Imaged Records entry route. Before opening any profile, record the directory URL, displayed source label, access date, clock time, timezone, and menu destination.

The separate [Imaged Records](https://www.rrc.texas.gov/resource-center/research/research-queries/imaged-records/) page supplies the official path into the imaged-record family. Preserve that route as provenance. Do not infer that a T-1 report exists merely because the family is available, and do not switch to a neighboring profile, form page, filing system, or EDI route because it appears easier to use.

This worksheet covers one authorized manual attempt. It does not create an automated research process. Do not scrape, poll, retrieve in volume, bypass access controls, automate CAPTCHA handling, or work around validation, timeout, session, or viewer behavior. When the official path cannot be completed as authorized, record the stop and use **unverified**.

## Lock profileId 29 and its source scope

The official [Imaged Records Query Menu](https://www.rrc.texas.gov/resource-center/research/research-queries/imaged-records/imaged-records-menu/) identifies **Monthly Transportation and Storage Reports (Form T-1)** and links it as `profileId=29`. Preserve the menu URL, displayed profile label, link destination, and access timestamp. The profile ID is route provenance; it is not a facility, operator, property, organization, or report identifier.

The menu states that the profile includes dates from January 2013 forward. Record that statement as **source-described coverage** with the access date. It does not establish continuous monthly coverage, report completeness, or the existence, identity, availability, or relevance of any particular report.

| Route or source                            | Boundary for this worksheet                                                          |
| ------------------------------------------ | ------------------------------------------------------------------------------------ |
| Form T-1 profileId 29                      | Preserve one manual attempt, displayed states, evidence, and source-described scope. |
| Form P-18 and other imaged-record profiles | Separate collections; do not merge their criteria or results.                        |
| Current T-1 forms and instructions         | Separate form materials; do not substitute them for an imaged-record result.         |
| RRC Online or T-1 EDI filing               | Separate submission systems; this worksheet does not prepare or submit a filing.     |
| Production and other electronic queries    | Separate systems with different criteria, coverage, and response states.             |
| Energy Depot or paid records research      | Outside this public, no-new-charge worksheet.                                        |

The form name is source terminology, not a substantive finding. It does not show that a report is complete, that data belongs to a reader's interest, or that any facility, operator, production, transportation, storage, inventory, compliance, ownership, or payment fact is true.

## Preserve the current HTTP 403 state

During article preparation, a direct request to the official profile route at `profileId=29` returned HTTP `403`. No profile page was captured, no criteria controls were verified, no values were entered, and no query completed. The defensible outcome for that attempt is **unverified**.

An access response is not a search result. HTTP `403`, a blocked page, an error, a timeout, a validation failure, a default screen, an interrupted session, a CAPTCHA, an unavailable viewer, or any incomplete attempt does not show that a report is absent. Preserve the route, timestamp, response state, stop point, and evidence reference without attempting a bypass.

## Build the attempt header before using controls

Assign a neutral attempt ID that does not expose a facility, operator, organization, property, ownership, or transaction value. Then preserve:

- the official directory, Imaged Records, menu, and profile URLs;
- the displayed Form T-1 profile label and `profileId=29`;
- the access date, clock time, and explicit timezone;
- the source-described January 2013-forward coverage note and access date;
- the authorized manual access method;
- the exact source-displayed criteria labels, if the profile loads;
- a controlled criteria-set reference and exact entered or selected values in that controlled record;
- the manual submit control or method;
- the displayed access, validation, submission, result, or interruption state;
- any report link, image, download, or viewer state actually presented;
- the retained evidence location, access restrictions, and file-integrity reference; and
- the transfer destination, recipient limits, unresolved questions, and recheck requirement.

Do not publish organization numbers, facility identifiers, districts, locations, reporting periods, or private-party values merely because a source accepts or displays them. Keep necessary values in an authorized controlled location and let the worksheet point to that record.

## Keep current form materials separate

The RRC [Oil and Gas Forms](https://www.rrc.texas.gov/oil-and-gas/oil-and-gas-forms/) page identifies Form T-1 as the Monthly Transportation and Storage Report and links the form family and instructions. The RRC's [February 15, 2024 notice](https://www.rrc.texas.gov/announcements/021524-nto-new-monthly-transportation-storage-report-and-skim-oilcondensate-report-available/) states that new Form T-1 versions became required on May 1, 2024 and describes several added filing fields. Those sources establish bounded form identity and dated current-form context. They do not complete the blocked `profileId=29` attempt.

Record four layers separately:

1. **Profile context:** the official menu label, profile ID, and source-described coverage.
2. **Attempt state:** what the authorized manual profile session displayed or prevented.
3. **Document state:** whether a responsive row, link, image, download, or viewer state appeared.
4. **Adjacent-source context:** what a separate form, instruction, filing, EDI, or query route says.

Never fill a gap in one layer with evidence from another. A current form does not prove that an imaged-record profile returned a result. A filing notice does not prove that any particular report was filed, accepted, complete, or retrievable. A profile label does not establish a production, transportation, storage, inventory, facility, operator, property, or ownership fact.

This worksheet does not explain how to complete Form T-1, decide who must file it, satisfy a filing obligation, submit an EDI record, interpret a reported quantity, reconcile balances, or test regulatory compliance. Those are different tasks and may require current agency instructions and qualified professional review.

## Record criteria without interpreting them

If the profile later loads, transcribe its displayed criteria labels exactly before entering anything. Preserve entered or selected values in a controlled record, not in a broadly distributed worksheet. Capture whether the source accepted the criteria and whether a manual submit action completed.

Do not redesign criteria, weaken a search, add guessed identifiers, or use facts from a neighboring system to force a response. One completed query with traceable criteria is more defensible than several undocumented variations. If criteria labels or accepted values cannot be tied to the same attempt, use **unverified**.

If a responsive item appears, preserve only what the source displayed: the result-row or link state, retrieval timestamp, document or viewer state, and evidence reference. Stop before interpreting report entries or drawing any facility, operator, engineering, production, transportation, storage, inventory, compliance, property, ownership, valuation, legal, tax, offer, or transaction conclusion.

## Apply fail-closed outcome rules

Use **located** only when a completed, attributable manual attempt in `profileId=29` displays responsive material. Located means that the recorded source attempt displayed something; it does not mean complete, correct, current, relevant, connected to a property, or legally sufficient.

Use **not located** only when every condition below is true:

1. the official Form T-1 profile loaded;
2. the displayed criteria labels were recorded;
3. the controlled criteria were accepted;
4. the manual submission completed;
5. the source displayed an empty result attributable to those criteria; and
6. no block, error, timeout, validation, session, CAPTCHA, viewer, or interpretation issue makes the attempt inconclusive.

Use **unverified** for every other state. The current HTTP `403` attempt is unverified. Do not repeat queries, change systems, use a filing route, purchase research, or use a neighboring profile merely to produce a different label.

## Blank provenance template

| Field                   | What to preserve                                                              |
| ----------------------- | ----------------------------------------------------------------------------- |
| Attempt ID              | Neutral internal identifier                                                   |
| Official route          | Directory, Imaged Records, menu, and profile URLs                             |
| Profile identity        | Displayed Form T-1 label and `profileId=29`                                   |
| Attempted at            | Date, clock time, and explicit timezone                                       |
| Source scope            | January 2013 forward, exactly as the menu described it, plus access date      |
| Access method           | One authorized manual attempt                                                 |
| Criteria schema         | Exact source-displayed labels, if accessible                                  |
| Controlled criteria ref | Restricted reference to exact entered or selected values                      |
| Submission state        | Not attempted, submitted, validation failed, interrupted, or unknown          |
| Access/result state     | Exact displayed state, HTTP response, error, timeout, or empty-result wording |
| Document/viewer state   | Responsive row, link, image, download, viewer state, or none displayed        |
| Evidence reference      | Restricted capture or response record with timestamp and integrity reference  |
| Outcome                 | Located, not located, or unverified                                           |
| Limitations             | Missing steps, access blocks, ambiguity, and prohibited inferences            |
| Recheck or handoff      | Authorized next step, responsible party, and source to revisit                |

Keep the worksheet blank until an actual authorized attempt supplies a field. Never use example identifiers that could be mistaken for a real organization, facility, report, district, property, owner, reporting period, or result.

## Handoff the record without expanding the claim

A later reviewer should be able to reproduce what happened without needing a substantive conclusion. Provide the official route, profile identity, timestamp, criteria reference, exact displayed state, evidence location, outcome rule used, limitations, and unresolved questions.

If the outcome is located, the reviewer still needs an independently authorized task before reading or interpreting a report. If it is not located, the label applies only to the recorded criteria and completed attempt. If it is unverified, preserve the stop point and do not convert uncertainty into absence.

The useful output is a narrow provenance record: one route, one profile, one controlled criteria set, one manual attempt, one evidence chain, and one bounded outcome. That record can support later research without turning retrieval mechanics into a substantive conclusion.
