> **Public retrieval boundary.** This article records one authorized manual attempt through the Texas Railroad Commission's Imaged Records **Skim Oil/Condensate Reports (Form P-18)** profile. It does not interpret a report or determine completeness, facility or well identity, production, storage, transportation, disposal, safety, environmental condition, compliance, property connection, ownership, title, lease, royalty, payment, acreage, value, offer quality, legal effect, tax, or transaction outcome. It does not provide legal, title, land, regulatory, environmental, geological, engineering, tax, accounting, appraisal, investment, or financial advice. MRX may have an economic interest in a later transaction; when that applies, the buyer relationship is disclosed in writing before an agreement is signed.

A **Texas RRC Form P-18 report retrieval** worksheet preserves how one manual source attempt occurred. It identifies the official route and profile, timestamps the attempt, records source-described coverage, points to controlled criteria, keeps access and result states separate, retains evidence, and assigns one bounded outcome.

Use only **located**, **not located**, or **unverified**. These labels describe one retrieval event. They do not turn a profile name, coverage statement, result row, document link, image, downloadable dataset, or empty state into a conclusion about a facility, well, property, owner, lease, production, royalty, valuation, offer, or transaction.

## Start with the official query directory

Open the Texas RRC [Research Queries](https://www.rrc.texas.gov/resource-center/research/research-queries/) directory and retain its current Oil and Gas Imaged Records entry route. Before opening any profile, record the directory URL, displayed source label, access date, clock time, timezone, and menu destination.

The separate [Imaged Records](https://www.rrc.texas.gov/resource-center/research/research-queries/imaged-records/) page supplies the official path into the imaged-record family. Preserve that route as provenance. Do not infer that a P-18 report exists merely because the family is available, and do not switch to a neighboring profile, download, or filing system because it appears easier to use.

This worksheet covers one authorized manual attempt. It does not create an automated research process. Do not scrape, poll, retrieve in volume, bypass access controls, automate CAPTCHA handling, or work around validation, timeout, session, or viewer behavior. When the official path cannot be completed as authorized, record the stop and use **unverified**.

## Lock profileId 28 and its source scope

The official [Imaged Records Query Menu](https://www.rrc.texas.gov/resource-center/research/research-queries/imaged-records/imaged-records-menu/) identifies **Skim Oil/Condensate Reports (Form P-18)** and links it as `profileId=28`. Preserve the menu URL, displayed profile label, link destination, and access timestamp. The profile ID is route provenance; it is not a facility, well, lease, organization, or report identifier.

The menu states that the profile includes dates from January 2013 forward. Record that statement as **source-described coverage** with the access date. It does not establish continuous monthly coverage, report completeness, or the existence, identity, availability, or relevance of any particular report.

| Route or source                          | Boundary for this worksheet                                                          |
| ---------------------------------------- | ------------------------------------------------------------------------------------ |
| Form P-18 profileId 28                   | Preserve one manual attempt, displayed states, evidence, and source-described scope. |
| P-17, T-1, G-10/W-10, and other profiles | Separate imaged-record collections; do not merge their criteria or results.          |
| Monthly P-18 JSON download               | Separate data route; do not substitute a file or automated parse for this attempt.   |
| LoneSTAR Form P-18 filing                | Separate submission system; this worksheet does not prepare or submit a filing.      |
| Production and other electronic queries  | Separate systems with different criteria, coverage, and response states.             |
| Energy Depot or paid records research    | Outside this public, no-new-charge worksheet.                                        |

The form name is source terminology, not a substantive finding. It does not show that a report is complete, that data belongs to a reader's interest, or that any facility, well, production, disposal, compliance, ownership, or payment fact is true.

## Preserve the current HTTP 403 state

During article preparation, a direct request to the official profile route at `profileId=28` returned HTTP `403`. No profile page was captured, no criteria controls were verified, no values were entered, and no query completed. The defensible outcome for that attempt is **unverified**.

An access response is not a search result. HTTP `403`, a blocked page, an error, a timeout, a validation failure, a default screen, an interrupted session, a CAPTCHA, an unavailable viewer, or any incomplete attempt does not show that a report is absent. Preserve the route, timestamp, response state, stop point, and evidence reference without attempting a bypass.

## Build the attempt header before using controls

Assign a neutral attempt ID that does not expose a facility, well, organization, property, ownership, or transaction value. Then preserve:

- the official directory, Imaged Records, menu, and profile URLs;
- the displayed Form P-18 profile label and `profileId=28`;
- the access date, clock time, and explicit timezone;
- the source-described January 2013-forward coverage note and access date;
- the authorized manual access method;
- the exact source-displayed criteria labels, if the profile loads;
- a controlled criteria-set reference and exact entered or selected values in that controlled record;
- the manual submit control or method;
- the displayed access, validation, submission, result, or interruption state;
- any report link, image, download, or viewer state actually presented;
- the retained evidence location, access restrictions, and file-integrity reference; and
- the transfer destination, recipient limits, unresolved questions, and recheck requirement.

Do not publish organization names, serial numbers, facilities, wells, leases, districts, locations, reporting periods, or private party values merely because a source accepts or displays them. Keep necessary values in an authorized controlled location and let the worksheet point to that record.

## Keep adjacent P-18 routes separate

The RRC's [P-18 download page](https://www.rrc.texas.gov/resource-center/research/data-sets-available-for-download/p-18-skim-oil-condensate-report/) identifies monthly P-18 reports as a separate JSON download. The official [Form P-18 instructions](https://www.rrc.texas.gov/media/uejn4oo3/p-18-instructions.pdf) provide form-purpose terminology. Those sources can identify the form family and distinguish routes. They do not complete the blocked `profileId=28` attempt.

Record four layers separately:

1. **Profile context:** the official menu label, profile ID, and source-described coverage.
2. **Attempt state:** what the authorized manual profile session displayed or prevented.
3. **Document state:** whether a responsive row, link, image, download, or viewer state appeared.
4. **Adjacent-source context:** what a separate download, instruction, filing, or query route says.

Never fill a gap in one layer with evidence from another. A downloadable file does not prove that the imaged profile returned a result. Form instructions do not prove a report was filed or accepted. A profile label does not establish a production, storage, disposal, facility, compliance, property, or ownership fact.

## Record criteria without interpreting them

If the profile later loads, transcribe its displayed criteria labels exactly before entering anything. Preserve entered or selected values in a controlled record, not in a broadly distributed worksheet. Capture whether the source accepted the criteria and whether a manual submit action completed.

Do not redesign criteria, weaken a search, add guessed identifiers, or use facts from a neighboring system to force a response. One completed query with traceable criteria is more defensible than several undocumented variations. If criteria labels or accepted values cannot be tied to the same attempt, use **unverified**.

If a responsive item appears, preserve only what the source displayed: the result-row or link state, retrieval timestamp, document or viewer state, and evidence reference. Stop before interpreting report entries or drawing any facility, well, engineering, production, storage, disposal, environmental, compliance, property, ownership, valuation, legal, tax, offer, or transaction conclusion.

## Apply fail-closed outcome rules

Use **located** only when a completed, attributable manual attempt in `profileId=28` displays responsive material. Located means that the recorded source attempt displayed something; it does not mean complete, correct, current, relevant, connected to a property, or legally sufficient.

Use **not located** only when every condition below is true:

1. the official Form P-18 profile loaded;
2. the displayed criteria labels were recorded;
3. the controlled criteria were accepted;
4. the manual submission completed;
5. the source displayed an empty result attributable to those criteria; and
6. no block, error, timeout, validation, session, CAPTCHA, viewer, or interpretation issue makes the attempt inconclusive.

Use **unverified** for every other state. The current HTTP `403` attempt is unverified. Do not repeat queries, change systems, parse a download, purchase research, or use a neighboring profile merely to produce a different label.

## Final quality check

Before closing the record, confirm that:

- the attempt began at the official Imaged Records route and preserved `profileId=28`;
- the timestamp includes a timezone;
- January 2013-forward coverage remains a dated source-scope note, not a completeness claim;
- source labels and any displayed criteria labels are exact;
- actual criteria values remain controlled and are not unnecessarily published;
- HTTP `403`, blocked, error, timeout, validation, default, session, CAPTCHA, and viewer states remain **unverified**;
- **not located** appears only after a completed empty result attributable to accepted recorded criteria;
- report-link, viewer, evidence, scope, and transfer states remain separate;
- other imaged-record profiles, downloads, filing systems, production queries, Energy Depot, and paid research were not merged;
- no automation, bulk retrieval, repeated-query workflow, bypass, CAPTCHA handling, or workaround occurred; and
- no report interpretation or facility, well, production, storage, disposal, environmental, compliance, property, ownership, lease, value, offer, legal, tax, or transaction conclusion was added.

If any item fails, retain **unverified**. The worksheet succeeds when it accurately preserves what happened, including a blocked attempt, without turning retrieval mechanics into a substantive conclusion.
