> **Public-record retrieval boundary.** This article records one Texas RRC Oil Proration Schedule Query attempt. It does not interpret a result, operator, district, lease number, field, county, schedule, date, link, document, or source context. It does not establish property connection, title, ownership, acreage, tract or unit inclusion, lease effect, payee status, royalty share, decimal, payment responsibility, entitlement, compliance, environmental condition, operating status, production, cash flow, value, price, offer quality, or a transaction result. It does not provide legal, title, land, tax, accounting, appraisal, engineering, geological, reserve, environmental, or financial advice. MRX may have an economic interest in a later transaction; when that applies, the buyer relationship is disclosed in writing before an agreement is signed.

A **Texas RRC Oil Proration query retrieval** worksheet answers one narrow question: exactly how was one official Oil Proration Schedule Query attempted? Record the entry route, source-displayed criteria, navigation steps, query-page state, retained reference, access timestamp, source limitation, and one bounded retrieval status.

Use only **located**, **not located**, or **unverified**. Those terms describe the query attempt. They do not decide whether a record is complete, connect any result to private property, or determine a lease, production, payment, compliance, value, or transaction outcome.

## Start with the named official route

The Railroad Commission of Texas [Research Queries](https://www.rrc.texas.gov/resource-center/research/research-queries/) directory lists an Oil Proration Schedule Query as a named Oil & Gas route. Preserve the full directory address and the complete [Oil Proration Schedule Query](https://webapps2.rrc.texas.gov/EWA/oilProQueryAction.do) address instead of recording a generic phrase such as “RRC proration search.”

The RRC’s [Oil & Gas Data Queries](https://www.rrc.texas.gov/resource-center/research/research-queries/about-oil-gas-data-queries/) page provides context for the public query environment. The Oil Proration Schedule Query help contents identify separate [search instructions](https://webapps2.rrc.texas.gov/EWA/help/Oil_Proration_HowTo.html) and an [about page](https://webapps2.rrc.texas.gov/EWA/help/OilProration_About.html). Preserve those route identities and access times. A route name or a visible screen label is not a conclusion about any record.

This worksheet owns one bounded Oil Proration Schedule Query attempt. It does not merge the route with a Wellbore Query, Inactive Well Query, H-10 Query, Organization Query, P-4 Query, production query, drilling-permit query, pooling filing, or a private lease review. For broader orientation, use [Texas Railroad Commission: How to Use Public Records to Understand Your Mineral Rights](/blog/texas-railroad-commission-how-to-use-public-records-to-understand-your-mineral-rights/).

## Create an attempt header before searching

Give the attempt a neutral ID such as “TX-OPQ-RET-01.” The ID labels a query session, not a property, lease, operator, field, production finding, or transaction conclusion.

Record these fields before entering criteria:

- **Attempt ID:** a stable internal label;
- **Purpose:** public Oil Proration Schedule Query retrieval only;
- **Official entry route:** the complete addresses opened;
- **Query-page label:** copied exactly as displayed;
- **Access date and time:** when the criteria screen was viewed;
- **Timezone:** attached to that timestamp;
- **Prepared by:** a role or controlled identifier;
- **Worksheet version:** the version used for this attempt; and
- **Source context or limitation:** the source-stated coverage, update, access, or display note.

Create a new attempt for a rerun. Do not overwrite a prior criteria snapshot or query-page state merely because the page, date, or displayed data changed.

## Capture each used criterion by its displayed label

The current [Oil Proration Schedule Query](https://webapps2.rrc.texas.gov/EWA/oilProQueryAction.do) screen displays criteria including **District**, **API Unique No.**, **Oil Lease No./Gas Well ID No.**, **Type Well**, **Field Type**, **County**, **Field(s)**, and **Operator(s)**, plus separate lease, field, and operator search actions. Its [official search help](https://webapps2.rrc.texas.gov/EWA/help/Oil_Proration_HowTo.html) provides query-specific guidance. Preserve the exact screen wording shown during the attempt rather than relying on memory.

Each criterion is a locator field, not a conclusion. Create one row for every field used:

- **Criterion label:** copied as displayed;
- **Entry method:** typed value, selected option, linked lookup, or left unused;
- **Controlled value reference:** the entered or selected value stored appropriately;
- **Format shown by source:** option label or instruction;
- **Used in submission:** yes or no; and
- **Capture note:** any displayed constraint, default, or warning that affected the attempt.

If a control was not used, record “unused.” Do not replace individual labels with a vague statement such as “searched proration schedules.” Do not publish real identifier values in a reusable example.

## Record the submission and navigation path

After submitting criteria, preserve only the route that actually occurred. A bounded path can look like:

**official directory → Oil Proration Schedule Query → criteria submitted → query-page state → displayed link or next route**

For each step, record:

- the displayed page or link label;
- the route or controlled route reference;
- the action taken;
- the access time and timezone;
- whether the page loaded, changed, timed out, or showed no rows; and
- the next step actually selected.

Do not reconstruct a sequence from memory. If the session ended, an error appeared, or a stated constraint prevented submission, preserve that event and use **not located** or **unverified** for the narrow retrieval fact.

## Keep query state and downstream meaning separate

The [Oil Proration Query Help Contents](https://webapps2.rrc.texas.gov/EWA/help/Oil_Proration_TOC.html) links to query-specific help sections. That identifies an information path; it does not establish the meaning, accuracy, completeness, legal effect, operating condition, production status, or property connection of an individual result.

Record the state separately from individual rows:

- **Criteria echoed by the query page:** exact labels and controlled values;
- **Displayed range or count:** copied as shown, if present;
- **Displayed sort, page, and page-size state:** only when displayed or used;
- **Query-page access time:** with timezone; and
- **Query-page message or source context:** copied or accurately paraphrased.

Then preserve only labels actually observed. A row may contain a displayed operator, district, lease, field type, county, field, date, or link label. Keep each label attached to its value and use “not displayed” when the source does not show a field. Matching text or numbers are not a property connection and do not establish production, value, or payment facts.

## Treat every new route as a new retrieval step

If a query page exposes a detail link, help page, document, or another official record channel, create a separate step with:

- originating attempt ID and result reference;
- displayed link or tab label;
- destination route or controlled reference;
- destination page label;
- new record class or fields displayed;
- access timestamp and timezone;
- retained reference location; and
- located, not located, or unverified.

The Oil Proration Schedule Query is not the same as an Inactive Well Query, Wellbore Query, H-10 Query, Organization Query, P-4 Query, production query, or lease-clause review. Do not combine a result from any of those routes into one implied operational, regulatory, property, payment, production, or transaction record.

The [Texas RRC Inactive Well Query Retrieval Provenance Worksheet](/blog/texas-rrc-inactive-well-query-retrieval-provenance-worksheet/) owns a different route. The [Texas RRC Wellbore Query Retrieval Provenance Worksheet](/blog/texas-rrc-wellbore-query-retrieval-provenance-worksheet/) owns another. Preserve those boundaries even when screens display similar labels.

## Use only bounded retrieval statuses

Keep the status vocabulary deliberately small:

- **Located:** the recorded official query exposed an identified result reference.
- **Not located:** the recorded attempt did not expose the sought result.
- **Unverified:** a label, identifier, route, or result appeared, but the narrow retrieval fact or relationship was not established.

Located does not mean connected, applicable, complete, accurate, current, compliant, productive, paid, valuable, or legally effective. Not located does not mean nonexistent. Unverified preserves uncertainty without alleging an error or defect.

Turn gaps into neutral retrieval questions:

- Which criterion or displayed source context narrowed this attempt?
- Did the query page echo every criterion as entered?
- Did the screen state any coverage, update, or display limit?
- Which page, sort, or navigation state was examined?
- Does the query expose a separate official route or controlled record channel?
- Which official source can describe the requested record class without converting it into a property conclusion?

## Preserve an authorized retained reference

The live query and a retained object are different evidence. For every authorized screenshot, export, or file, record:

- attempt ID;
- official route and navigation path;
- criteria snapshot;
- query-page and display state;
- result-row or next-route reference;
- access timestamp and timezone;
- controlled storage location;
- file hash when your records process uses one; and
- handling note for identifiers, names, well data, legal descriptions, account data, or other sensitive information.

Do not publish an actual query result, operator number, lease number, or property-specific record in a reusable worksheet. A controlled reference proves only what was retained for the recorded attempt.

Before closing the worksheet, confirm that:

- the exact official directory and Oil Proration Schedule Query routes are named;
- every submitted criterion retains its source label and controlled value;
- any instruction, default, source context, or limitation is captured as shown;
- the navigation path records only steps that occurred;
- query-page state, rows, detail links, and other query routes remain separate;
- the access timestamp, source context, and retained reference are attached;
- every status is only located, not located, or unverified;
- no row interprets a result, identifier, schedule, field, date, link, operator, county, district, or property relationship; and
- no row establishes title, ownership, acreage, unit inclusion, lease effect, payee status, payment responsibility, compliance, environmental condition, operating status, production, value, price, offer quality, or a transaction result.
