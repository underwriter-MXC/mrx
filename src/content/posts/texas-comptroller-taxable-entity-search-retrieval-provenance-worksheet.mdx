> **Single-source retrieval boundary.** This worksheet documents one authorized manual search through the Texas Comptroller's public Franchise Tax Account Status Search. It does not connect a displayed entity record to an offer sender, signer, representative, email, phone number, website, solicitation, property, or proposed transaction. It does not determine identity, legitimacy, authenticity, authority, endorsement, capacity, reputation, fairness, fraud, value, title, ownership, legal effect, or transaction quality. Keep real inputs, result values, addresses, identifiers, screenshots, and retained captures in an authorized controlled location. MRX may have an economic interest in a later transaction; when that applies, the buyer relationship is disclosed in writing before an agreement is signed.

A **Texas Comptroller taxable entity search retrieval** worksheet answers one narrow question: how was one manual public account-status search performed? It preserves the official route, one source-labeled field, a controlled input reference, access time and timezone, the displayed entity reference and status wording, a controlled evidence pointer, one bounded result, and one neutral next question.

The deliverable is not a buyer-screening score or a company profile. It is an attempt-level provenance record. If a later reviewer wants to compare the displayed entity with an offer, that is a separate job owned by the [mineral-rights offer sender identity cross-check](/blog/mineral-rights-offer-sender-identity-cross-check/).

## Create one neutral attempt record

Assign a neutral ID such as `TX-COA-01`. The ID identifies a search session, not an entity, taxpayer, offer, sender, signer, property, owner, or transaction.

Record:

- worksheet version and attempt ID;
- the official directory route and final search URL reached;
- access date, time, and timezone;
- the exact source-labeled field selected;
- a controlled reference to the input entered;
- the action taken immediately before the displayed state;
- the displayed entity reference and status wording, if any;
- the controlled evidence pointer;
- one bounded result label; and
- one neutral next question.

Use a new attempt ID for every rerun. Do not overwrite an earlier row because the field, input, route, page, timestamp, result, status wording, evidence, or source behavior changed.

## Start from the official Comptroller route

The Texas Comptroller's [database directory](https://comptroller.texas.gov/transparency/open-data/cpa-databases/) identifies the public Taxable Entity Search route. Preserve both the directory URL and the final [Franchise Tax Account Status Search](https://comptroller.texas.gov/taxes/franchise/account-status/search) URL that the browser reached.

Record redirects rather than hiding them. If the directory, search page, or final destination is unavailable, save the attempted route, timestamp, displayed state, and evidence pointer. Use `unverified` when the trail is not complete enough to reproduce.

Do not automate the route. This public worksheet does not authorize scraping, bulk collection, repeated scripted queries, access-control bypass, CAPTCHA bypass, session manipulation, or attempts to enter a secure account area.

## Use one of the three current search fields

The current public page exposes three search choices:

1. **Tax ID.** The page accepts an eleven-digit Comptroller taxpayer number or a nine-digit federal employer identification number.
2. **Entity Name.** Preserve the exact spelling, punctuation, spacing, and capitalization entered in the controlled record.
3. **Texas Secretary of State File Number.** Preserve leading zeros and the exact source-entered number in the controlled record.

Select one field for one attempt. If a different field needs to be tested, create a new attempt ID. Do not silently move an input from one field to another or combine several searches into one result label.

The public template should show placeholders such as `[controlled Tax ID]`, `[controlled entity name]`, or `[controlled SOS file number]`. Do not publish the real input merely to demonstrate the process. Federal employer identification numbers, account references, entity details, and result pages should remain in a location with access and retention controls.

## Preserve the displayed record without extending it

When the page displays a result, record only what an authorized reviewer needs to reproduce the attempt. That can include the displayed entity label, taxpayer or file reference, account-status wording, result timestamp or as-of context when shown, and a pointer to the retained evidence.

The Comptroller's [Franchise Tax Account Status overview](https://comptroller.texas.gov/taxes/franchise/coas-instructions.php) explains that printed search results reflect the agency's records at the time the query is made. That query-time boundary matters. A displayed record is not a timeless statement and should not be rewritten as one.

Do not use a similar entity name, mailing address, file number, registered-agent detail, or status phrase to claim that a person represents the entity. Do not link the record to a letter, email, phone call, website, offer, agreement, payment instruction, property, or mineral interest inside this worksheet.

## Assign only located, not located, or unverified

Choose one label after the attempt:

- **Located:** the recorded public search displayed the sought entity reference for the captured field and controlled input.
- **Not located:** the recorded attempt did not display the sought reference for that field, input, route, and access time.
- **Unverified:** the route, field, input, action, displayed state, evidence pointer, or source limitation was not captured well enough to support another label.

`Located` does not mean `same sender`, `authorized representative`, `endorsed`, `financially capable`, `safe`, `fair`, or `approved`. `Not located` does not mean the entity does not exist, the input is false, or a contact is impersonating someone. `Unverified` is the correct label when the evidence trail is incomplete.

## Separate retrieval from sender review

The [sender identity cross-check](/blog/mineral-rights-offer-sender-identity-cross-check/) compares a claimed sender across stated details, independent contact channels, public records, documents, and unresolved differences. This worksheet does none of that comparison.

The source row ends after it preserves the account-status retrieval. It must not answer:

- whether the person who contacted the owner works for the displayed entity;
- whether a signer has authority;
- whether an email domain, phone number, address, or website belongs to the entity;
- whether an offer is authentic, complete, fair, or enforceable;
- whether the entity has funds or intends to close;
- whether a property or mineral interest belongs in the proposed transaction; or
- whether the owner should respond, sign, sell, or hold.

Those questions require separate evidence and, where appropriate, qualified professional review. A public database result can support a next question; it cannot replace that work.

## Keep search results separate from certificates

The Comptroller distinguishes a public account-status search result from a purpose-specific certificate used for certain reinstatement or termination tasks. This worksheet does not request, order, certify, or interpret a certificate. It also does not prepare or submit an open-records request.

If a later legal, filing, tax, or transaction process requires a certificate, route that task separately to an authorized person who understands the exact purpose and current agency requirements. Do not describe the public search result as a certificate, state endorsement, legal opinion, or transaction approval.

## Retain evidence with access controls

An evidence pointer can identify:

- attempt ID and worksheet version;
- authorized case system, repository, or evidence-vault location;
- capture or note filename;
- source URL and final destination;
- capture timestamp and timezone;
- selected field and controlled input reference;
- file SHA-256 or another integrity reference;
- access role and retention rule; and
- whether another authorized reviewer repeated the attempt.

Share only records you are authorized to provide, through an approved channel, for a stated purpose. The [document redaction checklist](/blog/mineral-rights-document-redaction-checklist-before-sharing-records/) can help separate what a reviewer needs from identifiers and details that should remain controlled.

## Close with one source-specific question

End the row with one neutral question that stays inside the retrieval job. Examples include whether an authorized reviewer should repeat the same field after correcting a documented transcription issue, whether a different source-labeled field should receive its own attempt ID, or whether the evidence pointer is sufficient to reproduce the displayed state.

Do not end with a conclusion about the sender, entity, offer, property, owner, title, value, authority, endorsement, legal effect, or transaction. The worksheet is complete when another authorized reviewer can reproduce what was searched and understand exactly what the bounded result does and does not say.
