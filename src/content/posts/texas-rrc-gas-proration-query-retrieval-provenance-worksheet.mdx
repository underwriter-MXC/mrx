> **Public-record retrieval boundary.** This article records one Texas RRC Gas Proration Schedule Query attempt. It does not interpret a result, operator, district, identifier, field, date, link, document, or source context. It does not establish property connection, title, ownership, acreage, tract or unit inclusion, lease effect, payee status, royalty share, decimal, payment responsibility, entitlement, compliance, environmental condition, operating status, production, cash flow, value, price, offer quality, or a transaction result. It does not provide legal, title, land, tax, accounting, appraisal, engineering, geological, reserve, environmental, or financial advice. MRX may have an economic interest in a later transaction; when that applies, the buyer relationship is disclosed in writing before an agreement is signed.

A **Texas RRC Gas Proration query retrieval** worksheet answers one narrow question: exactly how was one official Gas Proration Schedule Query attempted? Record the entry route, source-displayed criteria, navigation steps, query-page state, retained reference, access timestamp, source limitation, and one bounded retrieval status.

Use only **located**, **not located**, or **unverified**. Those terms describe the attempt, not whether a record is complete or connected to private property. They do not decide a lease, production, payment, compliance, value, or transaction outcome.

## Start with the named official route

The Railroad Commission of Texas [Research Queries](https://www.rrc.texas.gov/resource-center/research/research-queries/) directory lists a Gas Proration Schedule Query as a named Oil & Gas route. Preserve the full directory address and complete [Gas Proration Schedule Query](https://webapps2.rrc.texas.gov/EWA/gasProQueryAction.do) address instead of recording a generic phrase such as “RRC gas search.”

The RRC’s [About Oil & Gas Data Queries](https://www.rrc.texas.gov/resource-center/research/research-queries/about-oil-gas-data-queries/) page provides context for the public query environment. The Gas Proration help contents identify separate [search instructions](https://webapps2.rrc.texas.gov/EWA/help/Gas_Proration_HowTo.html) and an [about page](https://webapps2.rrc.texas.gov/EWA/help/GasProration_About.html). Preserve those route identities and access times. A route name or visible screen label is not a conclusion about any record.

This worksheet owns one Gas Proration Schedule Query attempt. It does not merge the route with an Oil Proration, Wellbore, Inactive Well, H-10, Organization, P-4, production, drilling-permit, pooling-filing, or private lease-review route. For broader orientation, use [Texas Railroad Commission: How to Use Public Records to Understand Your Mineral Rights](/blog/texas-railroad-commission-how-to-use-public-records-to-understand-your-mineral-rights/).

## Create an attempt header before searching

Give the attempt a neutral ID such as `TX-GPQ-RET-01`. The ID labels a query session, not a property, field, operator, production finding, or transaction conclusion. Record the purpose, official entry routes, query-page label, access date and time, timezone, preparer role, worksheet version, and any source-stated coverage, update, access, or display note.

Create a new attempt for a rerun. Do not overwrite a prior criteria snapshot or query-page state merely because the page, date, or displayed data changed.

## Capture each used criterion by its displayed label

The current [Gas Proration Schedule Query](https://webapps2.rrc.texas.gov/EWA/gasProQueryAction.do) screen displays criteria including **District**, **API Unique No.**, **Oil Lease No./Gas Well ID No.**, **Type Well**, **Field Type**, **Field(s)**, and **Operator(s)**. Its [official search help](https://webapps2.rrc.texas.gov/EWA/help/Gas_Proration_HowTo.html) provides query-specific guidance. Preserve the exact screen wording shown during the attempt rather than relying on memory.

Each criterion is a locator field, not a conclusion. For every field used, record the displayed label, entry method, controlled value reference, format shown by the source, whether it was submitted, and any displayed default, constraint, or warning. If a control was not used, record “unused.” Do not publish real identifier values in a reusable example.

## Record the navigation that actually occurred

After submitting criteria, preserve only the route that occurred:

**official directory → Gas Proration Schedule Query → criteria submitted → query-page state → displayed link or next route**

For each step, record the displayed page or link label, controlled route reference, action taken, access time and timezone, whether the page loaded or changed, and the next step selected. If the session ended, timed out, showed no rows, or a stated constraint prevented submission, preserve that event and use **not located** or **unverified** only for the narrow retrieval fact.

The [Gas Proration Query Help Contents](https://webapps2.rrc.texas.gov/EWA/help/Gas_Proration_TOC.html) identifies a query-specific help path. That identifies an information path; it does not establish the meaning, accuracy, completeness, legal effect, operating condition, production status, or property connection of an individual result.

## Keep query state and downstream meaning separate

Record the query-page state separately from individual rows: criteria echoed by the page, any displayed count or range, displayed sort and page state, page access time, and a displayed message or source note. Then preserve only labels actually observed. Matching text or numbers are not a property connection and do not establish production, value, payment, title, lease, or compliance facts.

If a page exposes a detail link, help page, document, or another official record channel, create a separate retrieval step. Record its originating attempt ID, link label, destination route, destination page label, new fields displayed, access timestamp, controlled retained-reference location, and located/not located/unverified status. The [Texas RRC Oil Proration Query Retrieval Provenance Worksheet](/blog/texas-rrc-oil-proration-query-retrieval-provenance-worksheet/) and [Texas RRC Wellbore Query Retrieval Provenance Worksheet](/blog/texas-rrc-wellbore-query-retrieval-provenance-worksheet/) own different routes; preserve those boundaries even if screens display similar labels.

## Use only bounded retrieval statuses

- **Located:** the recorded official query exposed an identified result reference.
- **Not located:** the recorded attempt did not expose the sought result.
- **Unverified:** a label, identifier, route, or result appeared, but the narrow retrieval fact or relationship was not established.

Located does not mean connected, applicable, complete, accurate, current, compliant, productive, paid, valuable, or legally effective. Not located does not mean nonexistent. Unverified preserves uncertainty without alleging an error or defect.
