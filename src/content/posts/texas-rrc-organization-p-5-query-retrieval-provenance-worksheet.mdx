> **Public-record retrieval boundary.** This article records one Texas RRC Organization (P-5) Query attempt. It does not interpret an operator, organization number, company name, address, contact, officer, financial-assurance field, status, type, date, result row, or record. It does not establish property connection, title, ownership, acreage, tract or unit inclusion, lease effect, payee status, royalty share, decimal, payment responsibility, entitlement, compliance, completeness, accuracy, operating status, sale, production, cash flow, value, price, offer quality, or a transaction result. It does not provide legal, title, land, tax, accounting, appraisal, engineering, geological, reserve, investment, or financial advice. MRX may have an economic interest in a later transaction; when that applies, the buyer relationship is disclosed in writing before an agreement is signed.

A **Texas RRC Organization (P-5) query retrieval** worksheet answers one narrow question: exactly how was one official Organization (P-5) Query attempted? Record the entry route, source-displayed criteria, navigation steps, result-header state, result-row locator, access timestamp, source limitation, retained reference, and one bounded retrieval status.

Use only `located`, `not located`, or `unverified`. Those terms describe the query attempt. They do not interpret an organization record, establish a company relationship, or connect a displayed result to private property.

## Start with the named official route

The Railroad Commission of Texas [Research Queries](https://www.rrc.texas.gov/resource-center/research/research-queries/) directory lists the Organization (P-5) Query as a named Oil & Gas route. Its [Oil & Gas Data Query menu](https://webapps2.rrc.texas.gov/EWA/ewaMain.do) presents that route separately from production, wellbore, injection-storage, severance, P-4, proration, inactive-well, orphan-well, drilling-permit, inspection, and violation queries.

Open the named [Organization (P-5) Query](https://webapps2.rrc.texas.gov/EWA/organizationQueryAction.do) and preserve the complete HTTPS address. Do not write only `RRC search` or merge this route with a Wellbore, P-4, production, drilling-permit, or operator-name comparison workflow.

A reproducible attempt distinguishes:

- the Research Queries directory used as the entry point;
- the Oil & Gas Data Query menu;
- the Organization (P-5) Query criteria screen;
- the result list reached after submission;
- any displayed next route opened from a result; and
- any authorized screenshot or retained reference created during the attempt.

The RRC directory says online query data is continually updated, informational, non-authoritative, and without legal force or effect. Record that limitation with the access time. Do not turn a result into a claim that the online route is complete, current for every purpose, or legally controlling.

For broad orientation, use [Texas Railroad Commission: How to Use Public Records to Understand Your Mineral Rights](/blog/texas-railroad-commission-how-to-use-public-records-to-understand-your-mineral-rights/). This worksheet owns the smaller reproducibility record for one Organization Query execution.

## Create an attempt header before searching

Give the attempt a neutral ID such as `TX-ORG-RET-01`. The ID labels a query session, not a property, owner, company conclusion, or transaction.

Record these fields before entering criteria:

- **Attempt ID:** a stable internal label;
- **Purpose:** `public Organization (P-5) Query retrieval only`;
- **Official entry route:** the complete address opened;
- **Query-page label:** copied exactly as displayed;
- **Access date and time:** when the criteria screen was viewed;
- **Timezone:** the timezone attached to that timestamp;
- **Prepared by:** a role or controlled identifier;
- **Worksheet version:** the version used for this attempt; and
- **Source limitation:** the source's authority, update, access, coverage, or display note.

Create a new attempt for a later rerun. Do not overwrite an earlier criteria snapshot, result state, timestamp, or retained reference merely because the interface or displayed data changed.

## Capture each used criterion by its displayed label

The current [Organization (P-5) Query criteria screen](https://webapps2.rrc.texas.gov/EWA/organizationQueryAction.do) exposes an operator-selection path along with organization status, organization type, and P-5-related date-range fields. The [RRC overview](https://www.rrc.texas.gov/resource-center/research/research-queries/about-oil-gas-data-queries/) says the P-5 route can be searched by operator name or number and retrieves detailed information for that organization.

Those are locator fields, not conclusions. Create one row for every field used:

- **Criterion label:** copied as displayed;
- **Entry method:** typed value, selected option, helper, or left unused;
- **Controlled value reference:** the entered or selected value stored appropriately;
- **Format shown by source:** date format, option label, helper result, or leading characters;
- **Used in submission:** `yes` or `no`; and
- **Capture note:** any displayed instruction or default that affected the entry.

Avoid a summary such as `searched for a company`. Preserve each label and value separately. If a control remained at its default, record `unused` or the exact displayed default rather than inventing an entry.

## Record the submission and navigation path

After submitting criteria, preserve only the sequence that actually occurred. A bounded path can look like:

`official directory → query menu → Organization (P-5) Query → criteria submitted → result list → displayed next route`

For each step, record:

- the displayed page or link label;
- the route or controlled route reference;
- the action taken;
- the access time and timezone;
- whether the page loaded, changed, timed out, or showed no rows; and
- the next step actually selected.

Do not reconstruct a route from memory. If the session ended, an error appeared, or the interface changed, preserve that event and use `not located` or `unverified` for the narrow retrieval fact.

## Keep headers, displayed labels, and downstream meaning separate

The RRC overview describes an Organization Report as a Form P-5 filed by an operator subject to the Commission's rules, and it names organization information the report designates. That description identifies the source's terminology. It does not prove that a displayed company operates a particular property, has a private legal relationship, is entitled to money, is compliant for every purpose, or is connected to a mineral interest.

Record the result state separately from individual rows:

- **Criteria echoed by the result page:** exact labels and controlled values;
- **Displayed result range or count:** copied as shown, if present;
- **Display-limit message:** copied or accurately paraphrased, if shown or applicable;
- **Sort field and direction:** only when selected or displayed;
- **Page and page-size state:** the page or control actually reviewed;
- **Result-page access time:** with timezone; and
- **Result-page message or limitation:** copied or accurately paraphrased.

Then copy only fields actually observed, and keep every label attached to its value. A row might preserve a displayed organization number, name, status, type, filing-date label, or next-link label without deciding what the field means beyond the source screen. Use `not displayed` when the source does not show a field. Similar names and numbers are not interchangeable.

## Treat another route or data source as a new retrieval step

If a result exposes a new link, tab, record channel, or downloadable source, create a separate step with:

- originating attempt ID and result-row reference;
- displayed link or tab label;
- destination route or controlled reference;
- destination page label;
- new record class or fields displayed;
- access timestamp and timezone;
- retained reference location; and
- `located`, `not located`, or `unverified`.

The RRC's [About P-5 Organization Query](https://webapps2.rrc.texas.gov/EWA/help/P5Organization_About.html) page separately lists criteria, result columns, and a detail route exposed through an operator-number link. Preserve any opened detail page as a new retrieval step. A displayed status, address, phone number, financial-assurance field, resident-agent field, or officer field does not prove a property relationship, payment obligation, legal authority, or compliance conclusion.

Do not merge every linked page into one generic company record. Do not infer a property relationship from matching operator, company, lease, county, field, address, or P-5 labels. That downstream question belongs to an authorized review and remains outside this worksheet.

## Keep organization, P-4, wellbore, and name-comparison work separate

The query menu exposes separate Organization, P-4, production, Wellbore, and drilling-permit routes. This worksheet does not retrieve production periods or volumes, interpret a well or permit, decide a company relationship, or reconcile a displayed name across records.

Use explicit source-role labels:

- `public research directory`;
- `Oil & Gas Data Query menu`;
- `Organization (P-5) Query criteria screen`;
- `Organization Query result list`;
- `displayed next route or record channel`; or
- `authorized retained query reference`.

The [Texas RRC P-4 Gatherer/Purchaser Query Retrieval Provenance Worksheet](/blog/texas-rrc-p-4-gatherer-purchaser-query-retrieval-provenance-worksheet/) owns a different public route. The [operator-name change log](/blog/mineral-rights-operator-name-change-log/) owns a dated comparison of displayed names. Preserve the boundary even when a result contains a name or another route is available.

## Use only bounded retrieval statuses

Keep the status vocabulary intentionally small:

- **Located:** the recorded official query exposed an identified result reference.
- **Not located:** the recorded attempt did not expose the sought result.
- **Unverified:** a label, identifier, route, or result appeared, but the narrow retrieval fact or relationship was not established.

`Located` does not mean connected, applicable, complete, accurate, current, active, legally effective, contractually binding, compliant, paid, productive, or valuable. `Not located` does not mean nonexistent. `Unverified` preserves uncertainty without alleging an error or defect.

Turn gaps into neutral retrieval questions:

- Which criterion may have narrowed this attempt?
- Did the result header echo every criterion as entered?
- Did a display limit or page-size setting constrain what was reviewed?
- Which result page and sort state were examined?
- Does the row expose a separate official route or data source?
- Which official record channel may hold the record class sought?
- What authority, update, access, or coverage limitation does the source state?

Do not convert those questions into statements about ownership, title, acreage, lease effect, payment, compliance, operating status, production, development, reserves, or value.

## Preserve an authorized result reference

The live query and a retained object are different evidence. For every authorized screenshot, export, or file, record:

- attempt ID;
- official route and navigation path;
- criteria snapshot;
- result-header and display state;
- result-row or next-route reference;
- access timestamp and timezone;
- controlled storage location;
- file hash when your records process uses one; and
- handling note for identifiers, names, addresses, officer information, legal descriptions, account data, or other sensitive information.

Do not publish an actual organization number, contact record, owner record, private document, or property-specific result in a reusable example. A controlled reference proves only what was retained for the recorded attempt.

## Final quality check

Before closing the worksheet, confirm that:

- the exact official directory, menu, and Organization (P-5) Query routes are named;
- every submitted criterion preserves its source label and controlled value;
- the navigation path records only steps that occurred;
- result-header state, result rows, and next routes remain separate;
- result range, display limit, sorting, pagination, and page size are recorded only when displayed or used;
- the access timestamp, source limitation, and retained reference are attached;
- every status is only located, not located, or unverified;
- no row interprets an organization result, operator, company name, address, officer, status, type, date, or number;
- no row establishes property connection, ownership, title, acreage, unit inclusion, lease effect, payee status, payment responsibility, entitlement, compliance, completeness, or accuracy; and
- no row infers operating status, sale, production, cash flow, value, price, offer quality, or a transaction result.

A strong provenance worksheet is narrow by design. It lets an authorized reviewer understand and repeat the recorded Organization Query attempt. It does not decide what an organization record means.
