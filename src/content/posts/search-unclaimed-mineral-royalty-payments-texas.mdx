> **One-search administrative boundary.** This article documents one search through the official Texas unclaimed-property route for a possible mineral royalty payment. It does not promise that property exists; prove ownership, entitlement, title, or heirship; diagnose why a royalty payment stopped; reconcile operator suspense or pay-deck records; determine a correct decimal or amount; perform an RRC search; or provide legal, title, tax, accounting, appraisal, investment, or financial advice. Use only blank, redacted, or synthetic public examples. MRX may have an economic interest in a later transaction; when that applies, the buyer relationship is disclosed in writing before an agreement is signed.

A **Texas unclaimed mineral royalty payments search** log preserves one official state search attempt: source route, access time, exact name variant tested, apparent holder and property identifier exactly as displayed, controlled match-evidence reference, bounded result, claim-status checkpoint, and next administrative action. It separates what the public search showed from what an authenticated claim process may later establish.

The deliverable is a reproducible search record, not an entitlement decision. Use only `potential match located`, `no match displayed`, or `unverified`. Never convert a public name match into a statement that the property belongs to the searcher.

## Start from the official Texas route

The [Texas Comptroller unclaimed-property program page](https://comptroller.texas.gov/programs/unclaimed/) identifies mineral interests among examples of unclaimed property and directs businesses and individuals to ClaimItTexas. Starting from that agency page gives the searcher a controlled path to the official destination.

The current official portal is [ClaimItTexas](https://www.claimittexas.gov/). Confirm the final hostname before entering anything. A search-log record should preserve the starting agency page, the final portal URL, the access date, clock time, and explicit timezone. If the route redirects, record the final URL actually reached.

Do not use a paid locator, sponsored result, unsolicited message, or look-alike domain as the evidence source. Do not send a Social Security number, identity document, signature, claim number, banking information, or other sensitive material to an unverified person or site.

## Separate unclaimed property from other missing-payment paths

A state unclaimed-property search answers a narrow question: did the official public route display a possible property record for the exact name variant tested during this attempt?

It does not answer whether:

- an operator currently holds funds in suspense;
- a payment is delayed in ordinary processing;
- a division order, pay deck, or ownership record is correct;
- property was reported under another name or to another state;
- an owner, estate, trust, or heir has proved entitlement;
- a lease, well, tract, or production record connects to the result; or
- a buyer's offer or valuation is complete or fair.

The [Texas Comptroller announcement identifying mineral royalties](https://comptroller.texas.gov/about/media-center/news/20250131-texas-comptroller-glenn-hegar-observes-national-unclaimed-property-day-feb-1-1738168792964) supports using the state route as one possible lead. It does not say that every unpaid or missing royalty reaches the database. Keep this search separate from the ordinary payment workflow described in [How Royalty Payments Work for Texas Mineral Owners](/blog/how-royalty-payments-work-for-texas-mineral-rights-owners/) and from a mixed-status inventory assembled for a different review.

## Prepare a controlled name-variant list

Build the variant list before searching. Use the exact names already present in authorized records; do not guess at ownership or invent a person-to-property connection. Depending on the controlled source, separate variants may include:

- full legal name with the middle name spelled out;
- the same name with a middle initial;
- a prior surname or documented alternate spelling;
- an estate name exactly as shown in an authorized record;
- a trust name exactly as shown, including its dated designation when relevant; or
- a business name and a documented former name.

One attempt should cover one exact variant. Record capitalization, spacing, punctuation, suffixes, and abbreviations exactly as tested. Start a new attempt if any of those elements changes materially.

The public worksheet should not display a real person's full search history. Use a neutral attempt ID and keep the actual name variant in a controlled reference available only to an authorized reviewer.

## Record what the public result actually displays

For each attempt, preserve only the public result fields needed to reproduce or route the observation:

1. official starting page and final portal route;
2. access date, time, and timezone;
3. controlled reference to the exact name variant tested;
4. displayed apparent-owner name, retained only in a controlled record;
5. apparent holder exactly as displayed;
6. public property identifier or reference exactly as displayed;
7. property type or location field only when the portal displays it;
8. controlled screenshot or print reference, if authorized;
9. bounded result; and
10. next administrative checkpoint.

Do not add a county, operator, lease, well, amount, address, family relationship, or ownership conclusion that the official result did not display. Use `not displayed` when a field is absent. Use `unverified` if access fails, the source identity is uncertain, the interface does not finish loading, or the retained evidence is insufficient.

## Use bounded outcomes instead of conclusions

Use exactly these result labels:

- **Potential match located:** the official public route displayed a record that matched the controlled search criterion closely enough to preserve as a lead.
- **No match displayed:** the route did not display a match for that exact variant during the recorded attempt.
- **Unverified:** route access, source identity, interface behavior, search input, or evidence retention was insufficient to support either other label.

`Potential match located` does not mean `owned`, `owed`, `approved`, or `payable`. `No match displayed` does not mean `no money exists`, `nothing is owed`, or `the property was never reported`. The result belongs to one route, one exact variant, and one timestamp.

## Keep the claim checkpoint separate

The public search and the authenticated claim process are different stages. The [official ClaimItTexas FAQ](https://www.claimittexas.gov/app/faq-ucp) is the current place to review state instructions. Requirements may depend on the claimant and property record, so do not copy a fixed document list into a reusable article and present it as universal.

If an authorized person begins a claim, record only a controlled claim reference and one administrative status such as:

- not initiated;
- initiated through the authenticated official route;
- documentation requested;
- submitted and awaiting state review;
- additional information requested;
- closed by the claimant; or
- final state disposition retained in the controlled file.

Use the official claim-status route only after an authorized claimant has initiated a claim. Do not place a claim number, identity document, signature, tax identifier, bank record, or correspondence containing personal data in a public worksheet, image, screenshot, email thread, or shared folder without the required access controls.

## Preserve the statutory context without deciding entitlement

[Texas Property Code Chapter 74](https://statutes.capitol.texas.gov/Docs/PR/pdf/PR.74.pdf) addresses the report, delivery, and claims process for covered unclaimed property. It supplies context for why property may be held and claimed through the Comptroller, but it does not let a public searcher decide who is legally entitled to a particular record.

Keep legal interpretation out of the search log. If an apparent match raises an estate, trust, business succession, title, or competing-claim issue, preserve the state reference and route the narrow question to an appropriately qualified reviewer. Do not rewrite the result as a mineral-title conclusion.

## Blank unclaimed-royalty search-log template

| Field                         | What to preserve                                                                    |
| ----------------------------- | ----------------------------------------------------------------------------------- |
| Search attempt ID             | Neutral identifier with no personal data                                            |
| Official starting route       | Texas Comptroller page used to reach the search                                     |
| Final portal route            | Final official ClaimItTexas URL                                                     |
| Accessed at                   | Date, clock time, and explicit timezone                                             |
| Exact name-variant reference  | Controlled pointer to the unmodified person, estate, trust, or business name tested |
| Displayed apparent owner      | Controlled reference; do not expose it in a public example                         |
| Apparent holder               | Holder exactly as displayed, or `not displayed`                                     |
| Property reference            | Public property identifier exactly as displayed, retained in the controlled file    |
| Displayed type or location    | Exact displayed value, or `not displayed`                                           |
| Match-evidence reference      | Authorized location for a screenshot, print, or saved observation                  |
| Bounded result                | Potential match located, no match displayed, or unverified                          |
| Claim-status checkpoint       | Administrative state only; no entitlement conclusion                               |
| Sensitive-data location      | Approved authenticated route or controlled store, never the public worksheet        |
| Next administrative action    | Narrow responsible next step and owner                                              |
| Limitations                   | One search attempt; no ownership, title, heirship, payment, value, or legal finding  |

Keep the published template blank. A synthetic example may show the field structure, but it should not contain a real name, address, property identifier, claim number, holder account, amount, signature, or identity document.

## Handoff without turning a lead into proof

A useful handoff lets an authorized reviewer reconstruct the official route, exact variant, timestamp, displayed holder and property reference, evidence location, result label, and claim checkpoint. It does not decide entitlement or explain an unpaid royalty.

The search job is complete when every attempt has a bounded result, sensitive information remains controlled, and the next administrative owner is explicit. Ownership, heirship, title, operator suspense, payment reconciliation, valuation, offer review, and legal or tax interpretation remain separate workflows.
